ИгровыеФормы.ОдноразовыйТаймер (GameForms.SceneTreeTimer) Метод

Синтаксис

ОдноразовыйТаймер(<Обработчик>, <Интервал>)

Параметры

Обработчик (обязательный)
Тип: Действие (Action).
Обработчик события таймера.
Интервал (обязательный)
Тип: Число.
Время в миллисекундах до срабатывания таймера.

Возвращаемое значение

Описание

Создает событие после заданного интервала, без возможности повторения.

Примечание

Пример

ИФ.ОдноразовыйТаймер(ИФ.Действие(ЭтотОбъект, "ОдноразовыйТаймер"), 1000);
