СтильПанелиЛиния.ВесКонец (StyleBoxLine.GrowEnd) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает количество пикселей, на которое линия выйдет за пределы границ объекта. Если задано отрицательное значение, линия закончится внутри границ объекта. Значение по умолчанию - 1.

Примечание

Пример

СтильПанелиЛиния1.ВесКонец = 20;
