СтильПанели (StyleBox) Свойства

Свойства

ИмяРесурса (ResourceName) (унаследовано от Ресурс (Resource)) Необязательное имя для этого ресурса.
КлючЭлемента (ItemKey) (унаследовано от ОбъектГодо (GObject)) Возвращает уникальный ключ элемента сгенерированный при создании.
Метка (Tag) (унаследовано от ОбъектГодо (GObject)) Возвращает или задает объект, содержащий дополнительные данные.
ОтступСверху (ContentMarginTop) Возвращает или задает верхнее поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого сверху. Значение по умолчанию - -1.
ОтступСлева (ContentMarginLeft) Возвращает или задает левое поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого слева. Значение по умолчанию - -1.
ОтступСнизу (ContentMarginBottom) Возвращает или задает нижнее поле для содержимого этого блока стиля. Увеличение этого значения уменьшает доступное для содержимого пространство снизу. Значение по умолчанию - -1.
ОтступСправа (ContentMarginRight) Возвращает или задает правое поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого справа. Значение по умолчанию - -1.
ПутьРесурса (ResourcePath) (унаследовано от Ресурс (Resource)) Возвращает или задает уникальный путь к этому ресурсу. Если он был сохранен на диске, значением будет его путь к файлу.
