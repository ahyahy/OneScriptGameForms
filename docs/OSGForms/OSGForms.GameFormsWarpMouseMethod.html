ИгровыеФормы.ПереместитьМышь (GameForms.WarpMouse) Метод

Синтаксис

ПереместитьМышь(<Позиция>, <Длительность>)

ПереместитьМышь(<Элемент>, <Длительность>)

Параметры

Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция для перемещения курсора мыши.
Элемент (обязательный)
Тип: Произвольный.
Элемент, на который будет перемещен курсор мыши.
Длительность (необязательный)
Тип: Число.
Длительность перемещения в миллисекундах. Значение по умолчанию - 500 мс.

Возвращаемое значение

Описание

Перемещает курсор мыши в новую позицию.

Примечание

Пример

ИФ.ПереместитьМышь(ИФ.Вектор2(10, 10), 800);
Приостановить(1000);
ИФ.ПереместитьМышь(Кнопка1, 800);
Приостановить(1000);

Кнопка1.ПрограммноНажать();
