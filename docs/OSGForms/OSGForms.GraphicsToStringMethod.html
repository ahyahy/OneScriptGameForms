Синтаксис

ВСтроку()

Возвращаемое значение

Тип: Строка (String).

Строковое представление данного объекта.

Описание

Возвращает строковое представление данного объекта.

Примечание

Пример

Стр = Графика1.ВСтроку();
Сообщить("Графика1.ВСтроку() = " + Стр);
