Ориентация (Orientation) Перечисление

Описание

Указывает способ ориентации.

Это набор констант, определяющих основную ось расположения элементов внутри контейнера или направление движения ползунка в элементах управления. Оно переключает логику компоновки между горизонтальной (слева направо) и вертикальной (сверху вниз) плоскостями. Это фундаментальное свойство для гибкой верстки интерфейсов, позволяющее использовать один и тот же тип контейнера для создания как строк, так и столбцов, просто меняя одно значение.

Члены

Имя члена Описание Значение
Зет (Z) Направление в положительную сторону оси Z. 2
Игрек (Y) Направление в положительную сторону оси Y. 1
Икс (X) Направление в положительную сторону оси X. 0
