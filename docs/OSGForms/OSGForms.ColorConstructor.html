Цвет (Color) Конструктор

Синтаксис

Цвет()

Цвет(<Параметр>)

Цвет(<Красный>, <Зеленый>, <Синий>)

Цвет(<Красный>, <Зеленый>, <Синий>, <Альфа>)

Параметры

Параметр
Тип: Строка; Число.
Имя цвета или строка шестнадцатиричного значения или десятичное значение цвета.
Красный
Тип: Число.
Значение красной составляющей цвета.
Зеленый
Тип: Число.
Значение зеленой составляющей цвета.
Синий
Тип: Число.
Значение синей составляющей цвета.
Альфа
Тип: Число.
Значение альфа составляющей цвета.

Описание

Создаёт новый экземпляр класса Цвет (Color).
