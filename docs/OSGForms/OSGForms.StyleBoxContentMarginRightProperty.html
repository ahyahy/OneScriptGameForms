СтильПанели.ОтступСправа (StyleBox.ContentMarginRight) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает правое поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого справа. Значение по умолчанию - -1.

Примечание

Код, использующий этот блок стиля, должен решить, что это за содержимое: например, Кнопка (Button) учитывает это поле содержимого для текстового содержимого кнопки.
