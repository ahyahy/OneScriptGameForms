Таймер.ПриСрабатыванииТаймера (Timer.Timeout) Событие

Использование

Чтение и запись.

Значение

Тип: Действие (Action).

Возвращает или задает код для выполнения по истечении указанного интервала таймера.

Примечание

Аргументы события

Отправитель (Sender) Возвращает источник (объект) последнего события.
Параметр (Parameter) Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.

Пример

Таймер1.ПриСрабатыванииТаймера = ИФ.Действие(ЭтотОбъект, "Таймер1_ПриСрабатыванииТаймера");
