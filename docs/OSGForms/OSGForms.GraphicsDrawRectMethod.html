Графика.РисоватьПрямоугольник (Graphics.DrawRect) Метод

Синтаксис

РисоватьПрямоугольник(<Прямоугольник>, <Цвет>, <Заполнение>, <Ширина>, <Сглаживание>)

Параметры

Прямоугольник (обязательный)
Тип: Прямоугольник2 (Rect2).
Прямоугольник для отрисовки.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет прямоугольника.
Заполнение (необязательный)
Тип: Булево.
Заливка прямоугольника. Если Истина, круг будет залит указанным цветом. Если Ложь, круг будет нарисован как обводка с заданными цветом и шириной. Значение по умолчанию - Истина.
Ширина (необязательный)
Тип: Число.
Ширина обводки. Если параметр отрицательный, будут нарисованы двухточечные примитивы вместо четырехточечных. Это означает, что при масштабировании линии останутся тонкими. Если такое поведение нежелательно, передайте положительный параметр, например 1.0. Значение по умолчанию - -1.0. Параметр эффективен только в том случае, если параметр Заполнение равен Ложь.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует прямоугольник.

Примечание

Пример

Графика1 = ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.Графика());
Графика1.РисоватьПрямоугольник(ИФ.Прямоугольник2(ИФ.Вектор2(10, 10), ИФ.Вектор2(30, 30)), Иф.Цвет.Красный, Ложь, 5);
