Камера3д.ПолучитьОкно (Camera3D.GetWindow) Метод

Синтаксис

ПолучитьОкно()

Возвращаемое значение

Тип: Окно (Window).

Описание

Возвращает объект Окно (Window), содержащее этот узел. Если узел находится в главном окне, это эквивалентно получению корневого узла.
