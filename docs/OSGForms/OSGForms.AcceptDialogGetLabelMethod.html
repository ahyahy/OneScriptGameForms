Уведомление.ПолучитьНадпись (AcceptDialog.GetLabel) Метод

Синтаксис

ПолучитьНадпись()

Возвращаемое значение

Тип: Надпись (Label).

Описание

Возвращает объект Надпись (Label), используемый для показа текста.

Примечание

Пример

Надпись = Уведомление1.ПолучитьНадпись();
Сообщить("Надпись = " + Надпись);
