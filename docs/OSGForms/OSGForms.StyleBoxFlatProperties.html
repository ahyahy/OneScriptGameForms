СтильПанелиПлоский (StyleBoxFlat) Свойства

Свойства

ВылетСверху (ExpandMarginTop) Возвращает или задает расширение объекта за пределы прямоугольника управления на верхнем крае. Значение по умолчанию - 0.
ВылетСлева (ExpandMarginLeft) Возвращает или задает расширение объекта за пределы прямоугольника управления на левом краю. Значение по умолчанию - 0.
ВылетСнизу (ExpandMarginBottom) Возвращает или задает расширение объекта за пределы прямоугольника управления на нижнем крае. Значение по умолчанию - 0.
ВылетСправа (ExpandMarginRight) Возвращает или задает расширение объекта за пределы прямоугольника управления на правом краю. Значение по умолчанию - 0.
ИмяРесурса (ResourceName) (унаследовано от Ресурс (Resource)) Необязательное имя для этого ресурса. Значение по умолчанию - "StyleBoxFlat".
КлючЭлемента (ItemKey) (унаследовано от ОбъектГодо (GObject)) Возвращает уникальный ключ элемента сгенерированный при создании.
Метка (Tag) (унаследовано от ОбъектГодо (GObject)) Возвращает или задает объект, содержащий дополнительные данные.
ОтступСверху (ContentMarginTop) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает верхнее поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого сверху. Значение по умолчанию - -1.
ОтступСлева (ContentMarginLeft) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает левое поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого слева. Значение по умолчанию - -1.
ОтступСнизу (ContentMarginBottom) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает нижнее поле для содержимого этого блока стиля. Увеличение этого значения уменьшает доступное для содержимого пространство снизу. Значение по умолчанию - -1.
ОтступСправа (ContentMarginRight) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает правое поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого справа. Значение по умолчанию - -1.
ПутьРесурса (ResourcePath) (унаследовано от Ресурс (Resource)) Возвращает или задает уникальный путь к этому ресурсу. Если он был сохранен на диске, значением будет его путь к файлу.
РадиусВерхнегоЛевогоУгла (CornerRadiusTopLeft) Возвращает или задает радиус верхнего левого угла. Значение по умолчанию - 0.
РадиусВерхнегоПравогоУгла (CornerRadiusTopRight) Возвращает или задает радиус верхнего правого угла. Значение по умолчанию - 0.
РадиусНижнегоЛевогоУгла (CornerRadiusBottomLeft) Возвращает или задает радиус нижнего левого угла. Значение по умолчанию - 0.
РадиусНижнегоПравогоУгла (CornerRadiusBottomRight) Возвращает или задает радиус нижнего правого угла. Значение по умолчанию - 0.
РазмерТени (ShadowSize) Возвращает или задает размер тени в пикселях.. Значение по умолчанию - 0.
СмещениеТени (ShadowOffset) Возвращает или задает смещение тени в пикселях. Регулирует положение тени относительно объекта. Значение по умолчанию - Вектор2(0, 0).
ЦветГраницы (BorderColor) Возвращает или задает цвет границы. Значение по умолчанию - Цвет(204, 204, 204, 255).
ЦветТени (ShadowColor) Возвращает или задает цвет тени. Это не имеет никакого эффекта, если свойство РазмерТени (ShadowSize) меньше 1. Значение по умолчанию - Цвет(0, 0, 0, 153).
ЦветФона (BgColor) Возвращает или задает цвет фона. Значение по умолчанию - Цвет(153, 153, 153, 255).
ШиринаВерхнейГраницы (BorderWidthTop) Возвращает или задает ширину верхней границы. Значение по умолчанию - 0.
ШиринаЛевойГраницы (BorderWidthLeft) Возвращает или задает ширину левой границы. Значение по умолчанию - 0.
ШиринаНижнейГраницы (BorderWidthBottom) Возвращает или задает ширину нижней границы. Значение по умолчанию - 0.
ШиринаПравойГраницы (BorderWidthRight) Возвращает или задает ширину правой границы. Значение по умолчанию - 0.
