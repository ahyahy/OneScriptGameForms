Таймер (Timer) Класс

Описание

Обратный таймер. Создает событие после заданного интервала с возможностью создания повторяющихся событий.

Это узел, который отсчитывает заданное время и генерирует событие по истечении этого срока. Это основной инструмент для создания задержек, кулдаунов (перезарядки), таймеров обратного отсчета, периодических действий (например, нанесение урона каждую секунду) или ограничения времени уровня. Таймер работает независимо от игровой логики, но зависит от режима времени игры (может приостанавливаться вместе с игрой или работать в реальном времени).

Основные возможности

Одноразовый и циклический режим
  • Одноразовый: Метод ИгровыеФормы.ОдноразовыйТаймер (GameForms.SceneTreeTimer), срабатывает один раз, затем останавливается. Идеально для задержек ("взрыв через 3 секунды").
  • Циклический: Автоматически перезапускается после каждого срабатывания. Идеально для периодических событий ("мигание лампы").
    • Гибкое управление временем
  • Можно менять время ожидания (Интервал (WaitTime)) прямо во время работы таймера.
    • Событие истечения
  • Генерирует сигнал ПриСрабатыванииТаймера (Timeout), на который можно подписаться в коде. Это основной способ реакции на окончание отсчета.
