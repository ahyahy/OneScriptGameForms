Графика.РисоватьЭллипс (Graphics.DrawEllipse) Метод

Синтаксис

РисоватьЭллипс(<Позиция>, <БольшаяПолуось>, <МалаяПолуось>, <Цвет>, <Заполнение>, <Ширина>, <Сглаживание>)

Параметры

Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция элипса.
БольшаяПолуось (обязательный)
Тип: Число.
Большая полуось.
МалаяПолуось (обязательный)
Тип: Число.
Малая полуось.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет элипса.
Заполнение (необязательный)
Тип: Булево.
Заливка элипса. Если Истина, круг будет залит указанным цветом. Если Ложь, круг будет нарисован как обводка с заданными цветом и шириной. Значение по умолчанию - Истина.
Ширина (необязательный)
Тип: Число.
Ширина обводки. Если параметр отрицательный, будут нарисованы двухточечные примитивы вместо четырехточечных. Это означает, что при масштабировании линии останутся тонкими. Если такое поведение нежелательно, передайте положительный параметр, например 1.0. Значение по умолчанию - -1.0. Параметр эффективен только в том случае, если параметр Заполнение равен Ложь.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует эллипс с большой полуосью и малой полуосью.

Примечание

Пример

Графика1.РисоватьЭллипс(ИФ.Вектор2(50, 110), 40, 100, Иф.Цвет.Красный);
