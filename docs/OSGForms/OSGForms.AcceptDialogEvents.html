Уведомление (AcceptDialog) События

События

Отменено (Canceled) Возвращает или задает код, для события закрытия диалогового окна без подтверждения действия.
Подтверждено (Confirmed) Возвращает или задает код, для события принятия диалога, т.е. когда нажата кнопка OK.
