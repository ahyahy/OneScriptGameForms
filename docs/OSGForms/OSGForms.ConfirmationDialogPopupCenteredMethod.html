ОкноСообщений.РазвернутьВЦентре (ConfirmationDialog.PopupCentered) Метод

Синтаксис

РазвернутьВЦентре(<Текст>, <Заголовок>, <МинимальныйРазмер>, <Интервал>)

Параметры

Текст (необязательный)
Тип: Строка.
Текст сообщения. Значение по умолчанию - Сообщение.
Заголовок (необязательный)
Тип: Строка.
Заголовок сообщения. Значение по умолчанию - Сообщение.
МинимальныйРазмер (необязательный)
Тип: Вектор2ц (Vector2i).
Минимальный размер, до которого можно изменить размер окна.
Интервал (необязательный)
Тип: Число.
Время показа окна в миллисекундах. Значение по умолчанию - 0 мс.

Возвращаемое значение

Описание

Разворачивает (показывает) окно в центре текущего экрана с опционально заданным минимальным размером и временем показа.
