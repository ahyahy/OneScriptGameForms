СтильПанелиТекстура (StyleBoxTexture) Свойства

Свойства

ВертикальноеРастяжение (AxisStretchVertical) Возвращает или задает как текстура будет растягиваться или располагаться по вертикали. Значение по умолчанию - 0.
ВылетСверху (ExpandMarginTop) Возвращает или задает величину расширения верхнего поля этого стиля при рисовании, в результате чего оно отображается больше, чем требуется. Значение по умолчанию - 0.
ВылетСлева (ExpandMarginLeft) Возвращает или задает величину расширения левого поля этого стиля при рисовании, в результате чего оно отображается больше, чем требуется. Значение по умолчанию - 0.
ВылетСнизу (ExpandMarginBottom) Возвращает или задает величину расширения нижнего поля этого стиля при рисовании, в результате чего оно отображается больше, чем требуется. Значение по умолчанию - 0.
ВылетСправа (ExpandMarginRight) Возвращает или задает величину расширения правого поля этого стиля при рисовании, в результате чего оно отображается больше, чем требуется. Значение по умолчанию - 0.
ВылетТекстурыСверху (TextureMarginTop) Возвращает или задает увеличение верхнего поля текстуры 3×3. Более высокое значение означает, что большая часть исходной текстуры считается частью верхней границы поля 3×3. Значение по умолчанию - 0.
ВылетТекстурыСлева (TextureMarginLeft) Возвращает или задает увеличение левого поля текстуры 3×3. Более высокое значение означает, что большая часть исходной текстуры считается частью левой границы поля 3×3. Значение по умолчанию - 0.
ВылетТекстурыСнизу (TextureMarginBottom) Возвращает или задает увеличение нижнего поля текстуры 3×3. Более высокое значение означает, что большая часть исходной текстуры считается частью нижней границы поля 3×3. Значение по умолчанию - 0.
ВылетТекстурыСправа (TextureMarginRight) Возвращает или задает увеличение правого поля текстуры 3×3. Более высокое значение означает, что большая часть исходной текстуры считается частью правой границы поля 3×3. Значение по умолчанию - 0.
ГоризонтальноеРастяжение (AxisStretchHorizontal) Возвращает или задает как текстура будет растягиваться или располагаться по горизонтали. Значение по умолчанию - 0.
ИзменениеЦвета (ModulateColor) Возвращает или задает цвет текстуры при рисовании этого стиля. Значение по умолчанию - Белый (White).
ИмяРесурса (ResourceName) (унаследовано от Ресурс (Resource)) Необязательное имя для этого ресурса. Значение по умолчанию - "StyleBoxTexture".
КлючЭлемента (ItemKey) (унаследовано от ОбъектГодо (GObject)) Возвращает уникальный ключ элемента сгенерированный при создании.
Метка (Tag) (унаследовано от ОбъектГодо (GObject)) Возвращает или задает объект, содержащий дополнительные данные.
ОтступСверху (ContentMarginTop) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает верхнее поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого сверху. Значение по умолчанию - -1.
ОтступСлева (ContentMarginLeft) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает левое поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого слева. Значение по умолчанию - -1.
ОтступСнизу (ContentMarginBottom) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает нижнее поле для содержимого этого блока стиля. Увеличение этого значения уменьшает доступное для содержимого пространство снизу. Значение по умолчанию - -1.
ОтступСправа (ContentMarginRight) (унаследовано от СтильПанели (StyleBox)) Возвращает или задает правое поле для содержимого этого блока стиля. Увеличение этого значения уменьшает пространство, доступное для содержимого справа. Значение по умолчанию - -1.
ПутьРесурса (ResourcePath) (унаследовано от Ресурс (Resource)) Возвращает или задает уникальный путь к этому ресурсу. Если он был сохранен на диске, значением будет его путь к файлу.
Регион (RegionRect) Возвращает или задает прямоугольник для использования взятый из текстуры. Если пусто (Rect2(0, 0, 0, 0)), используется вся текстура. Значение по умолчанию - Rect2(0, 0, 0, 0).
РисоватьЦентр (DrawCenter) Возвращает или задает флаг отрисовки центрального элемента текстуры из девяти участков. Если Истина, будет нарисован центральный элемент текстуры из девяти участков. Значение по умолчанию - Истина.
Текстура (Texture) Возвращает или задает текстуру, используемую при рисовании этого стиля.
