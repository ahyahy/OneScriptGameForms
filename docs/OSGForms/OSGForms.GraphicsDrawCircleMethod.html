Графика.РисоватьКруг (Graphics.DrawCircle) Метод

Синтаксис

РисоватьКруг(<Позиция>, <Радиус>, <Цвет>, <Заполнение>, <Ширина>, <Сглаживание>)

Параметры

Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция круга в локальном пространстве.
Радиус (обязательный)
Тип: Число.
Радиус круга.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет круга.
Заполнение (необязательный)
Тип: Булево.
Заливка круга. Если Истина, круг будет залит указанным цветом. Если Ложь, круг будет нарисован как обводка с заданными цветом и шириной. Значение по умолчанию - Истина.
Ширина (необязательный)
Тип: Число.
Ширина обводки. Если параметр отрицательный, будут нарисованы двухточечные примитивы вместо четырехточечных. Это означает, что при масштабировании линии останутся тонкими. Если такое поведение нежелательно, передайте положительный параметр, например 1.0. Значение по умолчанию - -1.0. Параметр эффективен только в том случае, если параметр Заполнение равен Ложь.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует круг с позицией, заданной в локальном пространстве.

Примечание

Пример

Графика1.РисоватьКруг(ИФ.Вектор2(70, 70), 40, Иф.Цвет.Аквамариновый);
