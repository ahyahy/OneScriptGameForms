АргументыСобытия.ЭтоНажатие (EventArgs.Pressed) Свойство

Использование

Только чтение.

Значение

Тип: Булево.

Возвращает флаг нажатия клавиши для события ИгровыеФормы.КлавишаНажата (GameForms.KeyPress). Если Истина - клавиша была нажата, если Ложь - клавиша была отпущена.

Примечание

Пример

Аргументы = Иф.АргументыСобытия;
Сообщить("Аргументы.ЭтоНажатие = " + Аргументы.ЭтоНажатие);
