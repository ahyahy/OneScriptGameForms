Надпись.ПоворотНаГрадус (Label.RotationDegrees) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает вращение узла вокруг его опорной точки в градусах. Положительное значение соответствует повороту по часовой стрелке.

Примечание

В методе происходит преобразование угла из радиан в градусы, поэтому возвращенное значение может не соответствовать заданному в разрядах после запятой. 

Надпись1.ПоворотНаГрадус = 78.95;
ПоворотНаГрадус = Надпись1.ПоворотНаГрадус;
Сообщить("ПоворотНаГрадус =  " + ПоворотНаГрадус); // ПоворотНаГрадус =  78.94999694824219

Пример
