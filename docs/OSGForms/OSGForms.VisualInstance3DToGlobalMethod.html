ВизуальныйОбъект3д.ВГлобальные (VisualInstance3D.ToGlobal) Метод

Синтаксис

ВГлобальные(<ЛокальнаяТочка>)

Параметры

ЛокальнаяТочка (обязательный)
Тип: Вектор3 (Vector3).
Точка в локальном пространстве текущего узла.

Возвращаемое значение

Тип: Вектор3 (Vector3).

Абсолютные координаты этой точки в мировом пространстве сцены.

Описание

Возвращает глобальную точку, преобразованную из локального пространства этого узла в глобальное пространство.
