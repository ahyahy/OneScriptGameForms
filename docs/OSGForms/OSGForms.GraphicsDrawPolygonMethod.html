Графика.РисоватьМногоугольник (Graphics.DrawPolygon) Метод

Синтаксис

РисоватьМногоугольник(<СловарьТочекЦветов>, <ВнутренниеКоординаты>, <Текстура2д>)

Параметры

СловарьТочекЦветов (обязательный)
Тип: Словарь (Dictionary).
Словарь с точками и их цветом. Каждая запись словаря содержит точку и соответствующий ей цвет.
ВнутренниеКоординаты (необязательный)
Тип: Массив.
Массив из точек, представленных объектом Вектор2 (Vector2). Это координаты XY, но внутри картинки. Разрешается превышать размер картинки.
Текстура2д (необязательный)
Тип: Текстура2д (Texture2D).
Текстура2д.

Возвращаемое значение

Описание

Рисует сплошной многоугольник с любым количеством точек, выпуклый или вогнутый. В отличие от метода РисоватьЦветнойМногоугольник (DrawColoredPolygon), цвет каждой точки можно изменять индивидуально.

Примечание

Пример

Графика1 = ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.Графика());
Словарь1 = ИФ.Словарь();
Словарь1.Добавить(ИФ.Вектор2(10, 10), Иф.Цвет.БледноЗеленый);
Словарь1.Добавить(ИФ.Вектор2(600, 60), Иф.Цвет.ГлубокийРозовый);
Словарь1.Добавить(ИФ.Вектор2(530, 300), Иф.Цвет.Синий);
Словарь1.Добавить(ИФ.Вектор2(30, 200), Иф.Цвет.Золотарник);
Массив3 = Новый Массив();
Массив3.Добавить(ИФ.Вектор2(0, 0)); // Левая верхняя точка вырезки из ТекстураИзИзображения.
Массив3.Добавить(ИФ.Вектор2(110, 0)); // Правая верхняя точка вырезки из ТекстураИзИзображения.
Массив3.Добавить(ИФ.Вектор2(110, 70)); // Правая нижняя точка вырезки из ТекстураИзИзображения.
Массив3.Добавить(ИФ.Вектор2(0, 110)); // Левая нижняя точка вырезки из ТекстураИзИзображения.
ТекстураИзИзображения = ИФ.ТекстураИзИзображения(ОбъединитьПути(ТекущийСценарий().Каталог, "Волшебник.jpg"));
Графика1.РисоватьМногоугольник(Словарь1, Массив3, ТекстураИзИзображения);
