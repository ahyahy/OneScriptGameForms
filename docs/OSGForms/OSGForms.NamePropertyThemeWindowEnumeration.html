ИмяСвойстваТемыОкно (NamePropertyThemeWindow) Перечисление

Описание

Указывает имена свойств темы для окна.

Члены

Имя члена Описание Значение
ВнедреннаяГраница (EmbeddedBorder) Стиль панели, используемый при внедрении окна. Фон содержимого не будет виден, если не включено свойство окна Прозрачный (Transparent). embedded_border:Window
ВнедреннаяНеСфокусированнаяГраница (EmbeddedUnfocusedBorder) Стиль панели, используемый, когда окно встроено и не сфокусировано. embedded_unfocused_border:Window
ВысотаЗаголовка (TitleHeight) Высота строки заголовка. title_height:Window
ЗначокЗакрытия (Close) Значок кнопки закрытия. close:Window
ЗначокЗакрытияПриНажатии (ClosePressed) Значок кнопки закрытия при нажатии. close_pressed:Window
РазмерКонтураЗаголовка (TitleOutlineSize) Размер контура заголовка. title_outline_size:Window
РазмерШрифтаЗаголовка (TitleFontSize) Размер шрифта заголовка. title_font_size:Window
СмещениеЗахвата (ResizeMargin) Внешнее поле, за которое можно захватить границу окна мышью и изменить ее размер. resize_margin:Window
СмещениеКнопкиЗакрытияИгрек (CloseVOffset) Смещение вертикального положения кнопки закрытия относительно нижней части строки заголовка по направлению к верхней части строки заголовка. close_v_offset:Window
СмещениеКнопкиЗакрытияИкс (CloseHOffset) Горизонтальное смещение положения кнопки закрытия относительно конца строки заголовка в сторону начала строки заголовка. close_h_offset:Window
ЦветЗаголовка (TitleColor) Цвет текста заголовка. title_color:Window
ЦветКонтураЗаголовка (TitleOutlineModulate) Цвет контура текста заголовка. title_outline_modulate:Window
ШрифтЗаголовка (TitleFont) Шрифт, используемый для заголовка. title_font:Window
