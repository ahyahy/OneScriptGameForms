СтильПанелиПлоский.Сохранить (StyleBoxFlat.Save) Метод

Синтаксис

Сохранить(<Путь>)

Параметры

Путь (обязательный)
Тип: Строка.
Путь для ресурса.

Возвращаемое значение

Описание

Сохраняет ресурс на диске по указанному пути.

Примечание

Пример

СтильПанелиПлоский1.Сохранить(ПутьКопииРесурса);
Полный пример кода 



Перем ИФ, Кнопка1, СтильПанелиПлоский1, СтарыйПуть, НовыйПуть;
