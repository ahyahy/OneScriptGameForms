Графика.ПолучитьПозициюМыши (Graphics.GetLocalMousePosition) Метод

Синтаксис

ПолучитьПозициюМыши()

Возвращаемое значение

Тип: Вектор2 (Vector2).

Описание

Возвращает положение мыши на этом холсте относительно позиции элемента, используя локальную систему координат этого холста.

Примечание

Пример

Позиция = Графика1.ПолучитьПозициюМыши();
Сообщить("Позиция Икс =  " + Позиция.Икс + " Игрек = " + Позиция.Игрек);
