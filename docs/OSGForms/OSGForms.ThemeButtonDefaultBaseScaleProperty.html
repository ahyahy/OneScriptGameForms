ТемаКнопка.МасштабПоУмолчанию (ThemeButton.DefaultBaseScale) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает базовый масштабный коэффициент по умолчанию для этого ресурса темы. Используется некоторыми элементами управления для масштабирования их визуальных свойств на основе глобального масштабного коэффициента. Если это значение установлено на 0.0, используется глобальный масштабный коэффициент. Значение по умолчанию - 0.0.

Примечание

У свойства МасштабПоУмолчанию (DefaultBaseScale) есть известная особенность: движок применяет его не везде, где вы этого ждёте. В дефолтной теме движка на масштаб умножаются десятки элементов — шрифты, иконки, отступы, радиусы углов. А вот в кастомной теме МасштабПоУмолчанию (DefaultBaseScale) автоматически масштабирует сравнительно мало: например, толщину курсора в LineEdit - да, но размеры шрифтов, отступы и радиусы ваших стилей панели - нет. Поэтому МасштабПоУмолчанию (DefaultBaseScale) в кастомных темах - это скорее справочное значение, из которого вы сами умножаете свои величины в коде, а не автомасштабатор всей темы. Это зафиксировано как известная проблема в Годо.
