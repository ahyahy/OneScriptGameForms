ВертикальнаяГруппа (VBoxContainer) Класс

Описание

Контейнер, который располагает свои дочерние элементы управления вертикально. Вариант группы, которая может размещать дочерние элементы управления только горизонтально. Дочерние элементы управления автоматически перестраиваются при изменении их минимального размера.

Это конкретная реализация базового класса Группа (BoxContainer) с фиксированной вертикальной ориентацией. Он идеально подходит для создания меню, списков, форм настроек и любых интерфейсов, где элементы должны следовать друг за другом по вертикали, автоматически подстраиваясь под изменение размеров окна или содержимого.

Основные возможности

Автоматическая вертикальная раскладка
  • Первый добавленный элемент занимает верхнюю позицию, второй - сразу под ним, и так далее.
  • При добавлении или удалении элементов остальные автоматически сдвигаются, занимая освободившееся место.
    • Управление отступами
  • Свойство темы Разделение (Separation) задает фиксированный зазор (в пикселях) между всеми соседними элементами. Это позволяет избежать слипания кнопок или надписей без создания пустых узлов-распорок.
    • Гибкое растяжение (перечисление ФлагиРазмера (SizeFlags))
  • По умолчанию элементы занимают только необходимый им размер.
  • Если у дочернего элемента установлен флаг Расширять (Expand) по вертикали, он займет всё свободное пространство внутри группы.
  • Если у нескольких элементов стоит этот флаг, свободное место делится между ними поровну (или пропорционально их весу растяжения).
  • Флаг Заполнить (Fill) заставляет элемент растягиваться на всю ширину контейнера (по горизонтали).
    • Выравнивание
  • Свойство Выравнивание (Alignment) определяет положение элементов по горизонтальной оси, если их ширина меньше ширины самого контейнера (например: по левому краю, по центру, по правому краю или растянуть).
