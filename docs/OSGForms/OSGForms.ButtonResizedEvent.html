Кнопка.РазмерИзменен (Button.Resized) Событие

Использование

Чтение и запись.

Значение

Тип: Действие (Action).

Возвращает или задает код, выполняемый при изменении размера элемента управления.

Примечание

Аргументы события

Отправитель (Sender) Возвращает источник (объект) последнего события.
Параметр (Parameter) Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.

Пример

Кнопка1.РазмерИзменен = ИФ.Действие(ЭтотОбъект, "Кнопка1_РазмерИзменен");
