Методы

ВСтроку (ToString) (унаследовано от ОбъектГодо (GObject)) Возвращает строковое представление данного объекта.
Дублировать (Duplicate) (унаследовано от Ресурс (Resource)) Дублирует этот ресурс, возвращая новый ресурс со свойствами, скопированными из исходного.
Сохранить (Save) (унаследовано от Ресурс (Resource)) Сохраняет ресурс на диске по указанному пути.
УстановитьВылетВсех (SetExpandMarginAll) Устанавливает расширение объекта за пределы прямоугольника управления на указанное количество пикселей для всех сторон.
УстановитьРадиусУглаВсех (SetCornerRadiusAll) Устанавливает радиус угла равным указанному количеству пикселей для всех углов.
УстановитьШиринуГраницыВсех (SetBorderWidthAll) Устанавливает ширину границы на указанное количество пикселей для всех сторон.
