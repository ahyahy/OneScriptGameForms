Графика.РисоватьЭллиптическуюДугу (Graphics.DrawEllipseArc) Метод

Синтаксис

РисоватьЭллиптическуюДугу(<Центр>, <БольшаяПолуось>, <МалаяПолуось>, <НачальныйУгол>, <КонечныйУгол>, <КоличествоТочек>, <Цвет>, <Ширина>, <Сглаживание>)

Параметры

Центр (обязательный)
Тип: Вектор2 (Vector2).
Положение центра.
БольшаяПолуось (обязательный)
Тип: Число.
Большая полуось.
МалаяПолуось (обязательный)
Тип: Число.
Малая полуось.
НачальныйУгол (обязательный)
Тип: Число.
Начальный угол.
КонечныйУгол (обязательный)
Тип: Число.
Конечный угол.
КоличествоТочек (обязательный)
Тип: Число.
Количество точек. Чем больше значение КоличествоТочек, тем плавнее кривая.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет элиптической дуги.
Ширина (необязательный)
Тип: Число.
Ширина обводки. Значение по умолчанию - -1.0.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует незаполненную эллиптическую дугу между заданными углами с равномерными значениями цвета и ширины и опциональным сглаживанием (поддерживается только для положительных значений ширины).

Примечание

Дуга рисуется от значения параметра НачальныйУгол к значению параметра КонечныйУгол, то есть по часовой стрелке, если НачальныйУгол меньше КонечныйУгол, и против часовой стрелки в противном случае.

Пример

Графика1.РисоватьЭллиптическуюДугу(ИФ.Вектор2(55, 120), 40, 100, 40, 43, 25, Иф.Цвет.БледноЗеленый, 5);
