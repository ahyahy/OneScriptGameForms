Уведомление (AcceptDialog) Класс

Описание

Представляет диалог с указанным заголовком и текстом, используемый для уведомления пользователя.

Это специализированное модальное окно, предназначенное для отображения важного сообщения и получения от пользователя простого подтверждения (обычно ОК или Закрыть). В отличие от обычного окна, это диалоговое окно автоматически блокирует взаимодействие с остальной игрой или приложением, пока пользователь не нажмет кнопку подтверждения. Оно идеально подходит для сообщений об ошибках, предупреждений, уведомлений о сохранении или простых вопросов, не требующих сложного выбора.

Основные возможности

Модальность
  • При появлении окно затемняет фон и блокирует ввод для всех остальных элементов сцены. Пользователь не может игнорировать сообщение.
  • Закрывается только по нажатию кнопки подтверждения, клавиши Enter или Esc (в зависимости от настроек).
    • Стандартная структура
  • Содержит область для текста сообщения или произвольного узла, куда можно вставить сложную верстку (картинки, ссылки, форматированный текст).
  • Автоматически имеет кнопку подтверждения (по умолчанию подписана ОК или Принять).
    • Гибкость содержимого
  • Можно заменить стандартный текст на любой узел Контрол (например, сцену с подробным описанием ошибки или инструкцией).
  • Поддерживает настройку заголовка окна.
    • События реакции
  • Генерирует событие Подтверждено (Confirmed), когда пользователь нажал кнопку ОК. Это сигнал для продолжения выполнения кода (например, "Игрок понял предупреждение, можно запускать уровень").
