Цвет (Color) Методы

Методы

ВСтроку (ToString) Возвращает строковое представление цвета.
Получить10 (To10) Возвращает значение цвета десятичным числом.
Получить16 (To16) Возвращает значение цвета строкой в шестнадцатиричным формате включая альфа составляющую.
ПолучитьИз10 (From10) Возвращает объект Цвет (Color) из десятичного значения.
