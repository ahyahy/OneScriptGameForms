Изображение.ПолучитьПиксель (Image.GetPixel) Метод

Синтаксис

ПолучитьПиксель(<Икс>, <Игрек>)

Параметры

Икс (обязательный)
Тип: Число.
Координата X.
Игрек (обязательный)
Тип: Число.
Координата Y.

Возвращаемое значение

Тип: Цвет (Color).

Цвет пикселя в указанных координатах.

Описание

Возвращает цвет пикселя в указанных координатах.

Примечание

Пример

ЦветЦентра = Изображение.ПолучитьПиксель(70, 70);
