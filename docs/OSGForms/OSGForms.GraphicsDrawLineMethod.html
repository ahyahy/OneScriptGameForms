Графика.РисоватьЛинию (Graphics.DrawLine) Метод

Синтаксис

РисоватьЛинию(<ИсходнаяТочка>, <КонечнаяТочка>, <Цвет>, <Ширина>, <Сглаживание>)

Параметры

ИсходнаяТочка (обязательный)
Тип: Вектор2 (Vector2).
Точка начала линии.
КонечнаяТочка (обязательный)
Тип: Вектор2 (Vector2).
Точка окончания линии.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет линии.
Ширина (необязательный)
Тип: Число.
Ширина обводки. Если параметр отрицательный, будут нарисованы двухточечные примитивы вместо четырехточечных. Это означает, что при масштабировании линии останутся тонкими. Если такое поведение нежелательно, передайте положительный параметр, например 1.0. Значение по умолчанию - -1.0. Параметр эффективен только в том случае, если параметр Заполнение равен Ложь.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует линию от одной 2D точки к другой заданного цвета и ширины.

Примечание

Пример

Графика1.РисоватьЛинию(ИФ.Вектор2(10, 10), ИФ.Вектор2(320, 120), Иф.Цвет.Красный, 5);
