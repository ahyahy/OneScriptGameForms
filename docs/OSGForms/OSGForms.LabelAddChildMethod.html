Надпись.ДобавитьДочерний (Label.AddChild) Метод

Синтаксис

ДобавитьДочерний(<Элемент>)

Параметры

Элемент (обязательный)
Тип: Произвольный.
Добавляемый элемент.

Возвращаемое значение

Тип: Произвольный.

Описание

Добавляет дочерний элемент.

Примечание

Пример

Таймер1 = Надпись1.ДобавитьДочерний(ИФ.Таймер());
