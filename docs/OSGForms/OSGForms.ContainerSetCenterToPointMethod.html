Контейнер.ЦентрНаТочку (Container.SetCenterToPoint) Метод

Синтаксис

ЦентрНаТочку(<Точка>)

Параметры

Точка (обязательный)
Тип: Вектор2 (Vector2).
Точка в координатах родителя элемента.

Возвращаемое значение

Описание

Позиционирует элемент его центром на точку в координатах родителя.
