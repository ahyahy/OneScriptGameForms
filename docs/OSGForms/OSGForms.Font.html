Шрифт (Font) Класс

Описание

Базовый класс для шрифтов и вариаций шрифтов.

Это абстрактный базовый ресурс, определяющий набор глифов (символов), их размеры, отступы и правила отрисовки текста. Сам по себе этот класс не хранит данные шрифта напрямую, а служит общим интерфейсом для различных типов шрифтовых ресурсов. Когда вы видите свойство типа Шрифт (например, в Надпись, Кнопка или Тема), это означает, что туда можно поместить любой конкретный тип шрифта: системный шрифт, загруженный файл .ttf/.otf, растровый шрифт из картинки или шрифт, созданный из нескольких источников (BitmapFont).

Основные возможности

Универсальность источников
  • Позволяет использовать разные типы шрифтов в одних и тех же элементах интерфейса без изменения кода. Вы можете заменить системный шрифт на кастомный рукописный шрифт или пиксельный шрифт из картинки, просто поменяв ресурс.
    • Измерение текста
  • Предоставляет методы для расчета размеров текста до его отрисовки. Это критически важно для выравнивания, переноса строк и автоматического изменения размера кнопок под содержимое.
  • Можно узнать высоту строки, ширину конкретной строки или размер прямоугольника, необходимого для размещения текста.
    • Поддержка кернинга и интервалов
  • Учитывает кернинг (расстояние между конкретными парами символов) для улучшения читаемости.
  • Позволяет настраивать межбуквенный и межстрочный интервалы глобально для всего шрифта.
    • Динамическое создание
  • Некоторые наследники позволяют генерировать шрифт на лету из системных шрифтов операционной системы или из изображений, что полезно для процедурной генерации или локализации.
