Графика.РисоватьЧастьТекстурыПоПрямоугольнику (Graphics.DrawTextureRectRegion) Метод

Синтаксис

РисоватьЧастьТекстурыПоПрямоугольнику(<Текстура>, <ПрямоугольникНазначения>, <ПрямоугольникИсходный>, <ИзменениеЦвета>, <Транспонировать>, <Обрезать>)

Параметры

Текстура (обязательный)
Тип: ТекстураИзИзображения (ImageTexture).
Текстура для отрисовки.
ПрямоугольникНазначения (обязательный)
Тип: Прямоугольник2 (Rect2).
Прямоугольник, в котором отрисовываем часть текстуры.
ПрямоугольникИсходный (обязательный)
Тип: Прямоугольник2 (Rect2).
Прямоугольник, из которого берем часть текстуры.
ИзменениеЦвета (необязательный)
Тип: Цвет (Color).
Модуляция цвета. Значение по умолчанию - Белый.
Транспонировать (необязательный)
Тип: Булево.
Если параметр имеет значение Истина, координаты X и Y текстуры будут поменяны местами.
Обрезать (необязательный)
Тип: Булево.
Если параметр равен Истина (по умолчанию):

Возвращаемое значение

Описание

Рисует текстурированный прямоугольник из области текстуры (указанной параметром ПрямоугольникИсходный) в заданной позиции в локальном пространстве, опционально модулированный цветом.

Примечание

Пример

Графика1 = ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.Графика());

ТекстураИзИзображения = ИФ.ТекстураИзИзображения(ОбъединитьПути(ТекущийСценарий().Каталог, "Волшебник.jpg"));
Графика1.РисоватьЧастьТекстурыПоПрямоугольнику(
ТекстураИзИзображения, 
ИФ.Прямоугольник2(ИФ.Вектор2(10, 10), ИФ.Вектор2(300, 150)),
ИФ.Прямоугольник2(ИФ.Вектор2(20, 20), ИФ.Вектор2(120, 120)),
Иф.Цвет.Бежевый, Ложь, Ложь);
