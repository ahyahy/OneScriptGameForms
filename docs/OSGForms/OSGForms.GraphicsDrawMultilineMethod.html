Графика.РисоватьМультилинию (Graphics.DrawMultiline) Метод

Синтаксис

РисоватьМультилинию(<СловарьТочекДляЛиний>, <Цвет>, <Ширина>, <Сглаживание>)

Параметры

СловарьТочекДляЛиний (обязательный)
Тип: Словарь (Dictionary).
Словарь с точками. Каждая запись словаря содержит точку начала и точку окончания одной линии.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет мультилинии.
Ширина (необязательный)
Тип: Число.
Ширина. Значение по умолчанию - -1.0.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует несколько разрозненных линий с одинаковыми параметрами ширины и цвета. Каждая линия определяется двумя последовательными точками из массива, т.е. i-й сегмент состоит из points[2 * i], points[2 * i + 1] конечных точек.

Примечание

Пример

Графика1 = ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.Графика());
Словарь2 = ИФ.Словарь();
Словарь2.Добавить(ИФ.Вектор2(10, 10), ИФ.Вектор2(500, 450));
Словарь2.Добавить(ИФ.Вектор2(480, 506), ИФ.Вектор2(508, 530));
Словарь2.Добавить(ИФ.Вектор2(498, 520), ИФ.Вектор2(520, 450));
Словарь2.Добавить(ИФ.Вектор2(520, 470), ИФ.Вектор2(570, 430));
Графика1.РисоватьМультилинию(Словарь2, Иф.Цвет.ЗеленыйЛайм, 5);
