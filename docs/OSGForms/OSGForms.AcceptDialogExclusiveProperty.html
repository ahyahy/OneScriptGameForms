Уведомление.Модально (AcceptDialog.Exclusive) Свойство

Использование

Чтение и запись.

Значение

Тип: Булево.

Возвращает или задает флаг модального режима. Значение по умолчанию - Ложь.

Примечание

Пример

Уведомление1.Модально = Истина;
Полный пример кода 



Перем ИФ, Уведомление1;

	Сообщить("ОдноразовыйТаймер " + ИФ.ТекущаяДатаСМиллисекундами());
	
	Уведомление1.Модально = Истина;
	
	ИФ.СообщитьЕслиЛожь(Уведомление1.Модально
	, "Уведомление.Модально (AcceptDialog.Exclusive) Свойство");
	ИФ.Завершить();
