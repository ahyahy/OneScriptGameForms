АргументыСобытия (EventArgs) Свойства

Свойства

Включено (ToggledOn) Возвращает флаг переключения кнопки во включенное состояние.
КнопкаМыши (MouseButton) Возвращает значение перечисления, которое указывает нажатую кнопку мыши.
КодКлавиши (Keycode) Возвращает код клавиши для события ИгровыеФормы.КлавишаНажата (GameForms.KeyPress).
МаскаКнопокМыши (MouseButtonMask) Возвращает значение перечисления, которое указывает сочетание нажатых кнопок мыши.
Модификаторы (ModifiersMask) Возвращает код модификаторов клавиши для события ИгровыеФормы.КлавишаНажата (GameForms.KeyPress).
Отправитель (Sender) Возвращает источник (объект) последнего события.
Параметр (Parameter) Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.
Позиция (Position) Возвращает позицию элемента или курсора в координатах родительского узла.
ЭтоНажатие (Pressed) Возвращает флаг нажатия клавиши для события ИгровыеФормы.КлавишаНажата (GameForms.KeyPress). Если Истина - клавиша была нажата, если Ложь - клавиша была отпущена.
