ФлагПереносаСтроки (LineBreakFlag) Перечисление

Описание

Указывает способ разделения текста для переноса.

Это набор битовых флагов, определяющих правила автоматического переноса текста внутри узлов интерфейса (Надпись, Кнопка, ПравкаТекста) или при ручной отрисовке. Эти флаги указывают движку, как разбивать длинные строки на несколько линий, если они не помещаются в отведенную ширину, и как обрабатывать специальные символы.

Члены

Имя члена Описание Значение
Адаптивный (Adaptive) Следует использовать только в сочетании с ГраницаСлов (WordBound), разрывать линию между любыми не связанными между собой графемами, если разрыв между словами невозможен. 8
ГраницаСлов (WordBound) Разделение по границе между словами. 2
Графемы (GraphemeBound) Разделение между любыми не связанными между собой графемами. 4
ОбрезатьОтступ (TrimIndent) Вычитание ширины отступа первой строки из ширины всех строк после первой. 32
ОбрезатьСконца (TrimEndEdgeSpaces) Удаляет пробелы и символы переноса строки из конца разорванных сегментов строки. 128
ОбрезатьСначала (TrimStartEdgeSpaces) Удаляет пробелы и символы переноса строки из начала сегментов разорванной строки. 64
Обязательно (Mandatory) Разрыв строки выполняется в местах, где присутствуют обязательные символы разрыва строки. 1
Отсутствие (None) Без разделения. 0
