Свет3д (Light3D) Класс

Описание

Базовый класс для различных видов световых узлов.

Это абстрактный базовый класс для всех типов источников света в трехмерном пространстве. Он не используется напрямую для создания видимого света в сцене, а служит фундаментом, определяющим общие свойства и поведение, которые наследуются конкретными типами ламп.

Основные возможности

Универсальные настройки
  • Класс предоставляет единый интерфейс для управления параметрами, важными для любого источника света:
  • Цвет и яркость: Свойства ЦветСвета (LightColor) и СилаСвета (LightEnergy).
  • Тени: Включение/выключение теней, настройка их разрешения и смещения.
    • Абстрактная природа
  • Вы не можете добавить узел типа Свет3д (Light3D) в сцену и ожидать от него света. Необходимо использовать один из его конкретных наследников.
