ОкноСообщений (ConfirmationDialog) Класс

Описание

Представляет диалог, используемый для подтверждения действий.

Это специализированное модальное диалоговое окно, предназначенное для запроса подтверждения действия у пользователя. В отличие от простого Уведомление (AcceptDialog), оно всегда предлагает выбор между двумя вариантами: согласиться (Да) или отказаться (Нет). Это стандартный интерфейс для критических операций: удаление сохранений, выход из игры без сохранения, сброс настроек или подтверждение покупки. Окно блокирует остальной интерфейс, требуя обязательного ответа.

Основные возможности

Двойной выбор
  • Содержит две кнопки: Подтверждение (обычно Да, ОК, Удалить) и Отмена (обычно Нет, Отмена).
  • Позволяет пользователю безопасно отменить действие, нажав Отмена или Esc.
    • Модальность
  • При появлении затемняет фон и блокирует ввод для всей остальной сцены.
  • Закрывается автоматически после выбора любого варианта, возвращая управление игре.
    • Гибкая настройка текста
  • Можно менять заголовок окна, основной текст вопроса и подписи на обеих кнопках.
  • Поддерживает вставку произвольных узлов (Контрол) вместо простого текста для создания сложных вопросов (с иконками, форматированием).
    • Раздельные события
  • Генерирует два разных события: одно для подтверждения Подтверждено (Confirmed) и одно для отмены Отменено (Canceled). Это позволяет четко разделить логику выполнения и отмены действия.
