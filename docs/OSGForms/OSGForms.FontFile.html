ШрифтИзФайла (FontFile) Класс

Описание

Содержит набор глифов для представления символов Unicode, импортированных из файла шрифта.

Это конкретный ресурс, представляющий собой шрифт, загруженный из файла формата .ttf (TrueType), .otf (OpenType) или .ttc (Collection). В отличие от абстрактного Шрифт (Font) или растровых шрифтов, этот класс хранит векторные данные глифов, что позволяет отображать текст в любом размере без потери качества (пикселизации). Это самый распространенный тип шрифта в современных проектах, используемый для основного интерфейса, диалогов и меню, где важна четкость текста на экранах с любым разрешением.

Основные возможности

Масштабируемость без потерь
  • Поскольку шрифт векторный, вы можете изменять размер (в огромном диапазоне (от 8 до 500+ пикселей), и текст всегда останется четким и гладким. Движок растеризует глифы на лету под нужный размер.
    • Поддержка вариативных осей (Variable Fonts)
  • Если файл шрифта является вариативным (Variable Font), класс позволяет программно менять его характеристики через оси:
  • Вес (Weight): От тонкого (100) до жирного (900).
  • Ширина (Width): От узкого до широкого.
  • Это позволяет иметь один файл шрифта вместо десятков отдельных файлов для каждого начертания.
    • Настройка сглаживания
  • Позволяет управлять режимом сглаживания (антиалиасинга): Нет, Оттенки серого, LCD.
