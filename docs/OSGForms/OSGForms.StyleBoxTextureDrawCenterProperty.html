СтильПанелиТекстура.РисоватьЦентр (StyleBoxTexture.DrawCenter) Свойство

Использование

Чтение и запись.

Значение

Тип: Булево.

Возвращает или задает флаг отрисовки центрального элемента текстуры из девяти участков. Если Истина, будет нарисован центральный элемент текстуры из девяти участков. Значение по умолчанию - Истина.

Примечание

Пример

СтильПанелиТекстура1.РисоватьЦентр = Ложь;
