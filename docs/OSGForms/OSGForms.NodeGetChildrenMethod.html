Узел.ПолучитьДочерние (Node.GetChildren) Метод

Синтаксис

ПолучитьДочерние()

Возвращаемое значение

Тип: Массив.

Описание

Возвращает все дочерние элементы этого узла.

Примечание

Каждому элементу библиотеки соответствует элемент Годо. Но не каждому элементу Годо будет в соответсвие сопоставлен элемент игровых форм. В полном сопоставлении нет необходимости. Однако при получении дочерних элементов будут учтены все дочерние для узла Годо. В библиотеке не сопоставленным объектам будет присвоено значение Null. Таким образом при работе со свойством элемента ЗетИндекс (ZIndex) сохранится соответствие индексов. В библиотеке для некоторых индексов среди дочерних элементов будет соответсвовать значение Null.
