ИгровыеФормы.[Перечисление].Имя (GameForms.[Перечисление].Name) Метод

Синтаксис

[Перечисление].Имя(<Значение>)

Параметры

Значение (обязательный)
Тип: Произвольный.
Значение перечисления.

Возвращаемое значение

Тип: Строка.

Строковое представление значения перечисления.

Описание

Возвращает строковое представление значения перечисления.

Примечание

Пример

Сообщить("ИмяСвойстваТемыКнопка.Имя = " + ИФ.ИмяСвойстваТемыКнопка.Имя(ИФ.ИмяСвойстваТемыКнопка.ГоризонтальноеРазделение));
