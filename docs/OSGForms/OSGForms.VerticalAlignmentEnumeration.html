ВертикальноеВыравнивание (VerticalAlignment) Перечисление

Описание

Указывает вертикальное выравнивание текста.

Это набор констант, определяющих положение текста (или другого содержимого) внутри прямоугольной области узла по вертикальной оси (Y). Оно указывает, как текст должен располагаться, если высота контейнера больше, чем высота самого текста.

Члены

Имя члена Описание Значение
Верх (Top) Вертикальное выравнивание сверху, обычно для классов, содержащих текст. 0
Заполнение (Fill) Расширить строки по высоте, обычно для текстовых классов. 3
Низ (Bottom) Вертикальное выравнивание снизу, обычно для классов, содержащих текст. 2
Центр (Center) Вертикальное выравнивание по центру, обычно для классов, содержащих текст. 1
