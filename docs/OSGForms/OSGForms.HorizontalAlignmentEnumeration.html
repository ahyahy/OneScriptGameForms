ГоризонтальноеВыравнивание (HorizontalAlignment) Перечисление

Описание

Указывает горизонтальное выравнивание.

Это набор констант, определяющих положение текста (или другого содержимого) внутри прямоугольной области узла по горизонтальной оси (X). Оно указывает, как текст должен располагаться, если ширина контейнера больше, чем ширина самого текста.

Члены

Имя члена Описание Значение
Заполнение (Fill) Расширить строку по ширине, обычно для текстовых классов. 3
Лево (Left) Горизонтальное выравнивание по левому краю, обычно для классов, содержащих текст. 0
Право (Right) Горизонтальное выравнивание по правому краю, обычно для классов, содержащих текст. 2
Центр (Center) Горизонтальное выравнивание по центру, обычно для классов, содержащих текст. 1
