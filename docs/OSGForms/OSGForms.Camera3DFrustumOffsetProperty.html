Камера3д.СмещениеУсеченнойПирамиды (Camera3D.FrustumOffset) Свойство

Использование

Чтение и запись.

Значение

Тип: Вектор2 (Vector2).

Возвращает или задает смещение фрустума (frustum) камеры. Его можно изменить со значения по умолчанию, чтобы создать эффекты "наклонного фрустума". Значение по умолчанию - Вектор2(0, 0).

Это вектор (Вектор2), определяющий смещение центра видимой области (усеченной пирамиды обзора) камеры относительно её центральной оси. В отличие от поворота камеры, это свойство сдвигает саму область видимости в сторону, создавая эффект асимметричной проекции. Это мощный инструмент для создания специфических визуальных эффектов, таких как разделение экрана без искажения перспективы, реализация стереоскопического 3D (VR) и коррекция проекции в симуляторах, где камера не может быть размещена строго по центру экрана.
