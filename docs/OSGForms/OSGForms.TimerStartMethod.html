Таймер.Начать (Timer.Start) Метод

Синтаксис

Начать(<Интервал>)

Параметры

Интервал (необязательный)
Тип: Число.
Если интервал меньше 0 произойдет сброс таймера. Значение по умолчанию - -1.

Возвращаемое значение

Описание

Запускает таймер или сбрасывает его, если он уже был запущен.

Примечание

Пример

Таймер1.Начать();
