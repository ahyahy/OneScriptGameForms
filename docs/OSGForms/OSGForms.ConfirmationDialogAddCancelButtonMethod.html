ОкноСообщений.ДобавитьКнопкуОтмена (ConfirmationDialog.AddCancelButton) Метод

Синтаксис

ДобавитьКнопкуОтмена(<Текст>)

Параметры

Текст (обязательный)
Тип: Строка.
Текст кнопки.

Возвращаемое значение

Тип: Кнопка (Button).

Добавленная кнопка.

Описание

Добавляет кнопку с текстом и действие отмены в диалоговое окно и возвращает созданную кнопку. Вы можете использовать метод УдалитьКнопку (RemoveButton), чтобы удалить кнопку, созданную с помощью этого метода, из диалогового окна.
