ИгровыеФормы.МассивИменЦветов (GameForms.ColorNameArray) Метод

Синтаксис

МассивИменЦветов()

Возвращаемое значение

Тип: Массив.

Массив, содержащий имена цветов в русской и английской нотации.

Описание

Возвращает массив имен цветов для класса Цвет (Color).

Примечание

Пример

М = ИФ.МассивИменЦветов();
Сообщить("М = " + М.Количество());
Для А = 0 По М.ВГраница() Цикл
	Сообщить("Цвет = " + М[А]);
КонецЦикла;
