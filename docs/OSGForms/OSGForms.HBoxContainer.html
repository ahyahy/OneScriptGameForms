ГоризонтальнаяГруппа (HBoxContainer) Класс

Описание

Контейнер, который располагает дочерние элементы управления горизонтально.

Это конкретная реализация базового класса Группа (BoxContainer) с фиксированной горизонтальной ориентацией. Он идеально подходит для создания панелей инструментов, строк кнопок, форм ввода (метка + поле) и любых интерфейсов, где элементы должны располагаться в ряд, автоматически подстраиваясь под изменение ширины окна или содержимого.

Автоматическая горизонтальная раскладка
  • Первый добавленный элемент занимает левую позицию, второй - сразу справа от него, и так далее.
  • При добавлении или удалении элементов остальные автоматически сдвигаются, занимая освободившееся место.
    • Управление отступами
  • Свойство темы Разделение (Separation) задает фиксированный зазор (в пикселях) между всеми соседними элементами. Это позволяет избежать слипания кнопок или полей ввода без создания пустых узлов-распорок.
    • Гибкое растяжение (перечисление ФлагиРазмера (SizeFlags))
  • По умолчанию элементы занимают только необходимый им размер (минимальная ширина).
  • Если у дочернего элемента установлен флаг Расширять (Expand) по горизонтали, он займёт всё свободное пространство внутри группы.
  • Если у нескольких элементов стоит этот флаг, свободное место делится между ними поровну.
  • Флаг Заполнить (Fill) заставляет элемент растягиваться на всю высоту контейнера (по вертикали).
    • Выравнивание
  • Свойство Выравнивание (Alignment) определяет положение элементов по вертикальной оси, если их высота меньше высоты самого контейнера (например: по верхнему краю, по центру, по нижнему краю или растянуть).
