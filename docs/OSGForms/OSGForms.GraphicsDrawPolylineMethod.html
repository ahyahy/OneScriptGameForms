Графика.РисоватьПолилинию (Graphics.DrawPolyline) Метод

Синтаксис

РисоватьПолилинию(<МассивТочек>, <Цвет>, <Ширина>, <Сглаживание>)

Параметры

МассивТочек (обязательный)
Тип: Массив.
Массив точек для полилинии.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет полилинии.
Ширина (необязательный)
Тип: Число.
Ширина. Значение по умолчанию - -1.0.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует соединённые отрезки линий с одинаковым цветом и шириной. При рисовании большого количества линий это быстрее, чем использование отдельных вызовов РисоватьЛинию (DrawLine).

Примечание

Пример

Графика1 = ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.Графика());
Массив2 = Новый Массив();
Массив2.Добавить(ИФ.Вектор2(10, 10));
Массив2.Добавить(ИФ.Вектор2(450, 460));
Массив2.Добавить(ИФ.Вектор2(380, 500));
Массив2.Добавить(ИФ.Вектор2(350, 460));
Графика1.РисоватьПолилинию(Массив2, Иф.Цвет.Красный, 5);
