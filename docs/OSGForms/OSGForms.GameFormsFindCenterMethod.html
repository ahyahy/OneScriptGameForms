ИгровыеФормы.НайтиЦентр (GameForms.FindCenter) Метод

Синтаксис

НайтиЦентр(<Объект>)

Параметры

Объект (обязательный)
Тип: Произвольный.
Элемент управления, центр которого необходимо получить.

Возвращаемое значение

Тип: Вектор2 (Vector2).

Описание

Возвращает объект Вектор2 (Vector2) соответствующий центру переданного в параметре объекта, в координатах относительно родителя.

Примечание

Пример

Вектор2_3 = ИФ.НайтиЦентр(Кнопка1);
Сообщить("Вектор2_3 = Икс = " + Вектор2_3.Икс + " Игрек = " + Вектор2_3.Игрек);
