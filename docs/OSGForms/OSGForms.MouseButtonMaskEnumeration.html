МаскаКнопокМыши (MouseButtonMask) Перечисление

Описание

Указывает сочетание кнопок мыши как комбинированное значение при нажатии.

Это набор битовых флагов, представляющих состояние кнопок мыши в конкретный момент времени. В отличие от перечисления КнопкаМыши (MouseButton), которое идентифицирует конкретное событие нажатия или отпускания, маска используется для проверки того, какие кнопки зажаты прямо сейчас.

Члены

Имя члена Описание Значение
Дополнительная1 (Mb_xbutton1) Маска дополнительной кнопки мыши 1. 128
Дополнительная2 (Mb_xbutton2) Маска дополнительной кнопки мыши 2. 256
Левая (Left) Маска основной кнопки мыши, обычно для левой кнопки. 1
Правая (Right) Маска дополнительной кнопки мыши, обычно для правой кнопки. 2
Средняя (Middle) Маска средней кнопки мыши. 4
