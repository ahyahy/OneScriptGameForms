ПанельныйКонтейнер.ПолучитьСтильПанелиПусто (PanelContainer.GetThemeStyleboxEmpty) Метод

Синтаксис

ПолучитьСтильПанелиПусто(<ИмяСвойстваТемыДляКонтрола>)

Параметры

ИмяСвойстваТемыДляКонтрола (обязательный)
Тип: Произвольный.
Одно из значений перечисления ИмяСвойстваТемы... для контрола.

Возвращаемое значение

Тип: СтильПанелиПусто (StyleBoxEmpty).

Стиль панели для всех экземпляров этого класса.

Описание

Возвращает объект СтильПанелиПусто (StyleBoxEmpty) с указанным именем стиля. Имя стиля - это Одно из значений перечисления ИмяСвойстваТемы... для контрола.

Примечание

Возвращает запрошенный тип стиля из первой соответствующей темы в дереве, если эта тема имеет стиль такого типа. В противном случае будет создан новый экземпляр стиля запрошенного типа.

Пример

Стиль = ПанельныйКонтейнер1.ПолучитьСтильПанелиПусто(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель);
