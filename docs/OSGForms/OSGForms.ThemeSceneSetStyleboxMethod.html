ТемаСцена.УстановитьСтильПанели (ThemeScene.SetStylebox) Метод

Синтаксис

УстановитьСтильПанели(<ИмяСвойстваТемы>, <СтильПанели>)

Параметры

ИмяСвойстваТемы (обязательный)
Тип: Произвольный.
Одно из значений перечисления имен свойств темы для соответствующего элемента.
СтильПанели (обязательный)
Тип: Произвольный.
Устанавливаемый стиль панели.

Возвращаемое значение

Описание

Создает или изменяет значение свойства темы.

Примечание

Пример

// Создание стиля для фона заголовка.
СтильПанелиПлоский = ИФ.СтильПанелиПлоский();
СтильПанелиПлоский.ЦветФона = Иф.Цвет.Бисквитный;
СтильПанелиПлоский.ЦветГраницы = Иф.Цвет.БледноБирюзовый;
СтильПанелиПлоский.ВылетСверху = 80; // Должен совпадать с Иф.ИмяСвойстваТемыОкно.ВысотаЗаголовка? если нужно раскрасить заголовок в БледноБирюзовый.
СтильПанелиПлоский.ШиринаВерхнейГраницы = 80;
// ...
ТемаСцена1 = ИФ.ТемаСцена();
ТемаСцена1.УстановитьЦвет(Иф.ИмяСвойстваТемыНадпись.ЦветШрифта, Иф.Цвет.Синий);
ТемаСцена1.УстановитьЦвет(Иф.ИмяСвойстваТемыОкно.ЦветЗаголовка, Иф.Цвет.Красный);
ТемаСцена1.УстановитьКонстанту(Иф.ИмяСвойстваТемыОкно.ВысотаЗаголовка, 80);
ТемаСцена1.УстановитьКонстанту(Иф.ИмяСвойстваТемыОкно.СмещениеКнопкиЗакрытияИгрек, 60);
ТемаСцена1.УстановитьСтильПанели(ИФ.ИмяСвойстваТемыОкно.ВнедреннаяГраница, СтильПанелиПлоский);
