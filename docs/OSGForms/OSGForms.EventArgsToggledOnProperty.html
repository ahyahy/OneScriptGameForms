АргументыСобытия.Включено (EventArgs.ToggledOn) Свойство

Использование

Только чтение.

Значение

Тип: Булево.

Возвращает флаг переключения кнопки во включенное состояние.

Примечание

Пример

Аргументы = ИФ.АргументыСобытия;
Сообщить("Аргументы.Включено = " + Аргументы.Включено);
Полный пример кода 




Перем ИФ, Кнопка1;

	Кнопка1.РежимПереключателя = Истина;
	ИФ.ПереместитьМышь(Кнопка1);
	Кнопка1.ПрограммноНажать();
КонецПроцедуры

Процедура Кнопка1_ПриПереключении() Экспорт
	Сообщить("Кнопка1_ПриПереключении " + ИФ.ТекущаяДатаСМиллисекундами());
	
	Аргументы = ИФ.АргументыСобытия;
