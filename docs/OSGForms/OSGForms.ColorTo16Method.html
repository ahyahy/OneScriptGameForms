Цвет.Получить16 (Color.To16) Метод

Синтаксис

Получить16()

Возвращаемое значение

Тип: Строка.

Описание

Возвращает значение цвета строкой в шестнадцатиричным формате включая альфа составляющую.

Примечание

Пример

Цвет1 = ИФ.Цвет.Индиго;
Сообщить("Цвет1.Имя = " + Цвет1.Имя);
Сообщить("Цвет1.Получить16 = " + Цвет1.Получить16());
