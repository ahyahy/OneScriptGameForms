Действие.Сценарий (Action.Script) Свойство

Использование

Чтение и запись.

Значение

Тип: Произвольный.

Возвращает или задает сценарий как объект с типом значения OneScript.Contexts.IRuntimeContextInstance.

Примечание

Пример

Процедура Кнопка1_Нажатие() Экспорт
	Аргументы = Иф.АргументыСобытия;
	Сообщить("Действие1.Сценарий = " + Действие1.Сценарий);
	Сообщить("Действие1.ИмяМетода = " + Действие1.ИмяМетода);
	Сообщить("Аргументы.Параметр.Тортила = " + Аргументы.Параметр.Тортила);
	ИФ.СообщитьЕслиЛожь(Строка(ТипЗнч(Действие1.Сценарий)) = "Сценарий", "Действие.Сценарий (Action.Script) Свойство");
КонецПроцедуры
