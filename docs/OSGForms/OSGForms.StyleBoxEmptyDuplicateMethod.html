СтильПанелиПусто.Дублировать (StyleBoxEmpty.Duplicate) Метод

Синтаксис

Дублировать()

Возвращаемое значение

Тип: Ресурс (Resource).

Копия исходного ресурса.

Описание

Дублирует этот ресурс, возвращая новый ресурс со свойствами, скопированными из исходного.

Примечание

Пример

СтильПанелиПусто2 = СтильПанелиПусто1.Дублировать();
Полный пример кода
