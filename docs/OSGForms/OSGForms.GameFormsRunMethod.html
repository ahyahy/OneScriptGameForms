ИгровыеФормы.Запустить (GameForms.Run) Метод

Синтаксис

Запустить(<Путь>)

Параметры

Путь (необязательный)
Тип: Строка.
Путь до шаблона-заготовки Godot, представляющего собой исполняемый файл, скомпилированный в редакторе Godot.

Возвращаемое значение

Описание

Запускает приложение Godot.

Примечание

В этой справке шаблон-заготовка соответствует пути "C:\444\OneScriptGameForms\Scripts\OsGodot\os-forms\OsGForms.exe".

Пример

ИФ.Запустить(ОбъединитьПути(ИФ.КаталогБиблиотеки, "OsGForms.exe"));
