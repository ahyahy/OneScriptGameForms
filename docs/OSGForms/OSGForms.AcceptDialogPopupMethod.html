Уведомление.Развернуть (AcceptDialog.Popup) Метод

Синтаксис

Развернуть(<Текст>, <Заголовок>, <Прямоугольник>, <Интервал>)

Параметры

Текст (необязательный)
Тип: Строка.
Текст уведомления. Значение по умолчанию - Уведомление.
Заголовок (необязательный)
Тип: Строка.
Заголовок уведомления. Значение по умолчанию - Уведомление.
Прямоугольник (необязательный)
Тип: Прямоугольник2ц (Rect2i).
Положение и размер окна.
Интервал (необязательный)
Тип: Число.
Время показа окна в миллисекундах. Значение по умолчанию - 0 мс.

Возвращаемое значение

Описание

Разворачивает (показывает) окно и делает его переходным, то есть оно считается дочерним элементом другого окна. Переходное окно будет уничтожено вместе со своим переходным родителем и вернет фокус родителю при закрытии. Переходное окно отображается поверх родительского окна. Переходные окна не могут переходить в полноэкранный режим.

Примечание

Пример

Прямоугольник2ц = ИФ.Прямоугольник2ц();
Прямоугольник2ц.Позиция = ИФ.Вектор2ц(100, 100);
Прямоугольник2ц.Размер = ИФ.Вектор2ц(300, 100);
Уведомление1.Развернуть("Это уведомление.", "Заголовок", Прямоугольник2ц, 1000);
