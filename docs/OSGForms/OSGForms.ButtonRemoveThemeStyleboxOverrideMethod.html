Кнопка.УдалитьСтиль (Button.RemoveThemeStyleboxOverride) Метод

Синтаксис

УдалитьСтиль(<ИмяСвойстваТемыДляКонтрола>)

Параметры

ИмяСвойстваТемыДляКонтрола (обязательный)
Тип: Произвольный.
Одно из значений перечисления ИмяСвойстваТемы... для контрола.

Возвращаемое значение

Описание

Удаляет локальное переопределение для стиля элемента с указанным именем стиля, ранее добавленное методом ДобавитьСтиль (AddThemeStyleboxOverride).

Примечание

Пример

Кнопка1.УдалитьСтиль(ИФ.ИмяСвойстваТемыКнопка.Стандартное);
