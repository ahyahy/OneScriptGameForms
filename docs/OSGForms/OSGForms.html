Библиотека OSGForms Классы

Классы

АнимированныйСпрайт2д (AnimatedSprite2D) Представляет узел спрайта, содержащий несколько текстур в качестве кадров для анимации.
АргументыСобытия (EventArgs) Представляет класс, содержащий данные событий.
БиблиотекаКадров (SpriteFrames) Представляет библиотеку кадров спрайтов для классов АнимированныйСпрайт2д (AnimatedSprite2D) и АнимированныйСпрайт3д (AnimatedSprite3D).
Вектор2 (Vector2) Двумерный 2D вектор, использующий координаты с плавающей точкой.
Вектор2ц (Vector2i) Двумерный вектор, использующий целочисленные координаты.
Вектор3 (Vector3) Представляет трехмерный вектор, использующий координаты с плавающей точкой. Структура из 3 элементов, которая может использоваться для представления 3D-координат или любого другого триплета числовых значений.
Вектор3ц (Vector3i) Представляет трехмерный вектор, использующий целочисленные координаты. Структура из 3 элементов, которая может использоваться для представления координат сетки 3D или любого другого триплета целых чисел.
ВертикальнаяГруппа (VBoxContainer) Контейнер, который располагает свои дочерние элементы управления вертикально.
ВизуальныйОбъект3д (VisualInstance3D) Базовый класс. Представляет родительский элемент всех визуальных 3D-узлов.
Вьюпорт (Viewport) Базовый класс для окон. Инкапсулирует рисование и взаимодействие с игровым миром.
ВьюпортВложенный (SubViewport) Интерфейс к игровому миру, который не создает окно и не выводит изображение на экран напрямую.
ГоризонтальнаяГруппа (HBoxContainer) Контейнер, который располагает дочерние элементы управления горизонтально.
Графика (Graphics) Класс для рисования.
Группа (BoxContainer) Базовый класс. Представляет контейнер, который располагает свои дочерние элементы управления горизонтально или вертикально.
Действие (Action) Задает обработчик события.
Запись (Entry) Определяет пару "ключ-значение", которую можно задать или извлечь.
ИгровыеФормы (GameForms) Объект, содержащий свойства, методы, события для управления свободным игровым движком Godot Engine с открытым исходным кодом для 2D и 3D игр, а так же необходимые для этого объекты.
Изображение (Image) Представляет исходный тип данных изображения. Содержит данные изображения, которые могут быть преобразованы в объект ТекстураИзИзображения (ImageTexture), и предоставляет часто используемые методы обработки изображений.
Камера3д (Camera3D) Представляет специальный узел, который отображает то, что видно из его текущего местоположения.
Кнопка (Button) Тематическая кнопка, которая может содержать текст и значок.
КнопкаОснова (BaseButton) Базовый класс для кнопок графического интерфейса.
Кодировка (Encoding) Представляет кодировку символов.
Контейнер (Container) Базовый класс для всех контейнеров GUI.
Контрол (Control) Базовый класс для всех элементов управления GUI. Адаптирует свое положение и размер на основе родительского элемента управления.
Материал (Material) Базовый класс для применения визуальных свойств к объекту, таких как цвет и шероховатость.
Надпись (Label) Представляет элемент управления для отображения обычного текста. Он позволяет управлять горизонтальным и вертикальным выравниванием и может переносить текст внутри ограничивающего прямоугольника узла. Он не поддерживает жирный шрифт, курсив или другие форматированные текстовые элементы.
НаправленныйСвет3д (DirectionalLight3D) Представляет направленный свет с расстояния, например, от Солнца.
ОбъектГодо (GObject) Базовый класс для всех остальных классов в движке.
Окно (Window) Представляет узел, создающий окно. Окно может быть как собственным системным окном, так и встроенным в другое Окно.
ОкноСообщений (ConfirmationDialog) Представляет диалог, используемый для подтверждения действий.
Окружение (Environment) Представляет ресурс, который хранит все настройки глобального освещения, атмосферных эффектов и постобработки для 3D-сцены. Он определяет, как выглядит мир вокруг объектов: цвет неба, наличие тумана, свечение ярких участков (Bloom), тональную компрессию (HDR) и другие визуальные параметры. Этот класс не является узлом (Узел3д), а представляет собой данные (наследник Ресурс), которые назначаются камере (Камера3д) или глобальным настройкам сцены.
ОкружениеМира (WorldEnvironment) Представляет свойства среды по умолчанию для всей сцены (эффекты постобработки, настройки освещения и фона).
ПанельныйКонтейнер (PanelContainer) Контейнер, который использует для рисования стилизованные рамки.
Прямоугольник2 (Rect2) Двумерная ограничивающая рамка, выровненная по осям.
Прямоугольник2ц (Rect2i) Двумерная ограничивающая рамка, выровненная по осям, с использованием целочисленных координат.
Ресурс (Resource) Базовый класс для всех типов ресурсов, в первую очередь выступающий в качестве контейнеров данных.
Свет3д (Light3D) Базовый класс для различных видов световых узлов.
Словарь (Dictionary) Представляет коллекцию ключей и значений.
Спрайт2д (Sprite2D) Универсальный узел спрайта, отображающий 2D-текстуру.
СтильПанели (StyleBox) Базовый класс для рисования стилизованных рамок для элементов пользовательского интерфейса.
СтильПанелиЛиния (StyleBoxLine) Представляет класс, который отображает одну линию заданного цвета и толщины. Линия может быть как горизонтальной, так и вертикальной. Полезно для разделителей.
СтильПанелиПлоский (StyleBoxFlat) Представляет настраиваемый стиль панели, не использующий текстуру. Настраивая различные свойства этого класса, вы можете добиться многих общих видов без необходимости использования текстуры. Это включает в себя опциональные скругленные границы, сглаживание, тени и наклон.
СтильПанелиПусто (StyleBoxEmpty) Пустой стиль рамки, который можно использовать для отображения ничего вместо стиля по умолчанию.
СтильПанелиТекстура (StyleBoxTexture) Представляет текстурный девяти-сторонний стиль панели.
Строка (String) Представляет текст в виде последовательности символов Unicode.
СчетчикСсылок (RefCounted) Базовый класс для любого объекта, который хранит счетчик ссылок.
Таймер (Timer) Обратный таймер. Создает событие после заданного интервала с возможностью создания повторяющихся событий.
Текстура (Texture) Базовый класс для всех типов текстур.
Текстура2д (Texture2D) Базовый класс. Текстура для 2D и 3D. Текстура работает путем регистрации изображения в видеооборудовании, которое затем может использоваться в 3D-моделях или 2D объектах Sprite2D или элементах управления. Текстуры часто создаются путем загрузки их из файла. Примечание: Максимальный размер текстуры составляет 16384×16384 пикселей из-за ограничений графического оборудования. Большие текстуры могут не импортироваться.
ТекстураИзИзображения (ImageTexture) Представляет текстуру, созданную на основе изображения.
Тема (Theme) Базовый класс, используемый для стилизации, оформления объектов Контрол (Control) и Окно (Window) и их потомков.
ТемаВертикальнаяГруппа (ThemeVBoxContainer) Представляет ресурс, используемый для стилизации, оформления объектов ВертикальнаяГруппа (VBoxContainer) и их потомков.
ТемаГоризонтальнаяГруппа (ThemeHBoxContainer) Представляет ресурс, используемый для стилизации, оформления объектов ГоризонтальнаяГруппа (HBoxContainer) и их потомков.
ТемаКнопка (ThemeButton) Представляет ресурс, используемый для стилизации, оформления объектов Кнопка (Button) и их потомков.
ТемаНадпись (ThemeLabel) Представляет ресурс, используемый для стилизации, оформления объектов Надпись (Label) и их потомков.
ТемаОкно (ThemeWindow) Представляет ресурс, используемый для стилизации, оформления объектов Окно (Window) и их потомков.
ТемаОкноСообщений (ThemeConfirmationDialog) Представляет ресурс, используемый для стилизации, оформления объектов ОкноСообщений (ConfirmationDialog) и их потомков.
ТемаПанельныйКонтейнер (ThemePanelContainer) Представляет ресурс, используемый для стилизации, оформления объектов ПанельныйКонтейнер (PanelContainer) и их потомков.
ТемаСцена (ThemeScene) Представляет ресурс, используемый для стилизации, оформления объектов корневого узла сцены (ИгровыеФормы.КорневоеОкно (GameForms.RootWindow)) и его потомков.
ТемаУведомление (ThemeAcceptDialog) Представляет ресурс, используемый для стилизации, оформления объектов Уведомление (AcceptDialog) и их потомков.
Трансформация3д (Transform3D) Матрица 3×4, представляющая трехмерное преобразование.
Уведомление (AcceptDialog) Представляет диалог с указанным заголовком и текстом, используемый для уведомления пользователя.
Узел (Node) Базовый класс для всех объектов.
Узел2д (Node2D) Игровой 2D-объект, наследуемый всеми 2D-узлами. Имеет позицию, поворот, масштаб и наклон.
Узел3д (Node3D) Базовый класс. Является базовым представлением узла в трехмерном пространстве. Все остальные трехмерные узлы наследуются от этого класса.
Холст (CanvasItem) Базовый класс для всего, что находится в двумерном пространстве.
Цвет (Color) Цвет, представленный в формате RGBA (красный, зеленый, синий, альфа-канал).
Шрифт (Font) Базовый класс для шрифтов и вариаций шрифтов.
ШрифтВариативный (FontVariation) Предоставляет вариации OpenType, имитацию жирного/наклонного начертания и дополнительные настройки шрифта.
ШрифтИзФайла (FontFile) Содержит набор глифов для представления символов Unicode, импортированных из файла шрифта.
