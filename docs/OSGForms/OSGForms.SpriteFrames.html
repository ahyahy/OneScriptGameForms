БиблиотекаКадров (SpriteFrames) Класс

Описание

Представляет библиотеку кадров спрайтов для классов АнимированныйСпрайт2д (AnimatedSprite2D) и АнимированныйСпрайт3д (AnimatedSprite3D).

Это ресурс, предназначенный для хранения и организации последовательностей кадров (изображений), которые используются для создания двумерной анимации. Сам по себе этот класс не отображается на экране; он служит библиотекой кадров, которую используют узлы анимации (например, (AnimatedSprite2D) или АнимированныйСпрайт3д (AnimatedSprite3D)) для воспроизведения движения.
