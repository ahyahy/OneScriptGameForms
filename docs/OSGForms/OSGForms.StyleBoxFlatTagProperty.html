СтильПанелиПлоский.Метка (StyleBoxFlat.Tag) Свойство

Использование

Чтение и запись.

Значение

Тип: Произвольный.

Возвращает или задает объект, содержащий дополнительные данные.

Примечание

Пример

Сообщить("Метка.Тортила = " + ПанельныйКонтейнер1.ПолучитьСтильПанелиПлоский(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель).Метка.Тортила);

Процедура ОдноразовыйТаймер() Экспорт
	Сообщить("ОдноразовыйТаймер " + ИФ.ТекущаяДатаСМиллисекундами());
	
	ПанельныйКонтейнер1.ДобавитьСтиль(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель, СтильПанелиПлоский1);
	
	Сообщить("Метка.Тортила = " + ПанельныйКонтейнер1.ПолучитьСтильПанелиПлоский(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель).Метка.Тортила);
	ИФ.СообщитьЕслиЛожь(ПанельныйКонтейнер1.ПолучитьСтильПанелиПлоский(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель).Метка.Тортила = "Добрая черепаха, которая подарила Буратино золотой ключик.", 
	"СтильПанелиПлоский.Метка (StyleBoxFlat.Tag) Свойство");
	ИФ.Завершить();
