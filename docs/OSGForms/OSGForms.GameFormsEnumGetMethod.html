ИгровыеФормы.[Перечисление].Получить (GameForms.[Перечисление].Get) Метод

Синтаксис

[Перечисление].Получить(<Индекс>)

Параметры

Индекс (обязательный)
Тип: Число.
Индекс в коллекции.

Возвращаемое значение

Тип: Строка.

Описание

Возвращает элемент перечисления по индексу.

Примечание

Пример

Сообщить("Модификаторы.Получить(2) = " + ИФ.Модификаторы.Получить(2));
