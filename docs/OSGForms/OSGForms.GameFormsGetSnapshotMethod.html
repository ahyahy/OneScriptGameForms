ИгровыеФормы.ПолучитьСнимок (GameForms.GetSnapshot) Метод

Синтаксис

ПолучитьСнимок(<Узел>, <Путь>, <ФорматИзображения>)

Параметры

Узел (обязательный)
Тип: Произвольный.
Наследуемые типы от типа Узел (Node).
Путь (обязательный)
Тип: Строка.
Путь, по которому будет сохранен снимок.
ФорматИзображения (необязательный)
Тип: ФорматИзображения (ImageFormat).
Формат изображения для сохраняемого файла снимка. Значение по умолчанию - Png (Png).

Возвращаемое значение

Тип: Изображение (Image).

Снимок родительского окна.

Описание

Возвращает объект Изображение (Image), который представляет собой снимок окна, которому принадлежит узел.

Примечание

Расширение указанного в параметре Путь имени файла будет проигнорировано и установлено в соответствии с перечислением, указанном в параметре ФорматИзображения.

Пример

Изображение = ИФ.ПолучитьСнимок(Графика1, ИФ.НормализоватьПуть(Путь), ИФ.ФорматИзображения.Png);

	ИФ.Завершить();
