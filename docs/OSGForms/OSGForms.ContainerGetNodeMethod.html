Контейнер.ПолучитьУзел (Container.GetNode) Метод

Синтаксис

ПолучитьУзел(<Имя>)

Параметры

Имя (обязательный)
Тип: Строка.
Имя искомого дочернего элемента.

Возвращаемое значение

Тип: Произвольный.

Дочерний элемент или Неопределено, если дочернего с указанным именем не найдено.

Описание

Возвращает дочерний узел по его имени.
