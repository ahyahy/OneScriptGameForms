Уведомление.НеИзменяемыйРазмер (AcceptDialog.Unresizable) Свойство

Использование

Чтение и запись.

Значение

Тип: Булево.

Возвращает или задает значение, указывающее, можно ли изменять размер окна. Значение по умолчанию - Ложь.

Примечание

Пример

Уведомление1.НеИзменяемыйРазмер = Истина;
Сообщить("Уведомление1.НеИзменяемыйРазмер = " + Уведомление1.НеИзменяемыйРазмер);
