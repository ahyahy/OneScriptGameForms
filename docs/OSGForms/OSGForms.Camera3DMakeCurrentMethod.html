Камера3д.СделатьТекущей (Camera3D.MakeCurrent) Метод

Синтаксис

СделатьТекущей()

Возвращаемое значение

Описание

Делает эту камеру текущей, то есть той, через которую игрок (или пользователь) видит мир в данный момент. Метод сканирует текущую сцену. Если есть другая камера, у которой стоит статус текущая, она автоматически становится неактивной (перестает рендерить изображение). Вызывающая камера получает статус текущая. Изображение на экране мгновенно меняется на вид из этой камеры.
