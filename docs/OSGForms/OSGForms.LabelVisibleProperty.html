Надпись.Отображать (Label.Visible) Свойство

Использование

Чтение и запись.

Значение

Тип: Булево.

Возвращает или задает флаг возможности быть видимым. Если Истина, этот объект может быть нарисован. Будет ли этот объект нарисован на самом деле, зависит от видимости всех его предков.

Примечание

Пример

Надпись1.Отображать = Ложь;
Полный пример кода
