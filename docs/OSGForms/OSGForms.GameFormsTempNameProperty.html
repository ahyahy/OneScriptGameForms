ИгровыеФормы.СлучайноеИмя (GameForms.TempName) Свойство

Использование

Только чтение.

Значение

Тип: Строка.

Возвращает уникальную комбинацию символов для имени временного файла, сформированную на основе GUID.

Примечание

Пример

СтарыйПуть = ОбъединитьПути(ТекущийСценарий().Каталог, ИФ.СлучайноеИмя + "my_stylebox.tres");;
НовыйПуть = ОбъединитьПути(ТекущийСценарий().Каталог, ИФ.СлучайноеИмя + "my_stylebox_copy.tres");
