ПанельныйКонтейнер.ЦентрНаТочку (PanelContainer.SetCenterToPoint) Метод

Синтаксис

ЦентрНаТочку(<Точка>)

Параметры

Точка (обязательный)
Тип: Вектор2 (Vector2).
Точка в координатах родителя элемента.

Возвращаемое значение

Описание

Позиционирует элемент его центром на точку в координатах родителя.

Примечание

Пример

Вектор2 = ИФ.НайтиЦентр(ИФ.КорневоеОкно);
ПанельныйКонтейнер1.ЦентрНаТочку(ИФ.Вектор2(Вектор2.Икс - 5, Вектор2.Игрек - 40));
