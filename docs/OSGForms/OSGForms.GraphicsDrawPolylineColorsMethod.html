Графика.РисоватьЦветнуюПолилинию (Graphics.DrawPolylineColors) Метод

Синтаксис

РисоватьЦветнуюПолилинию(<СловарьЛинийЦветов>, <Ширина>, <Сглаживание>)

Параметры

СловарьЛинийЦветов (обязательный)
Тип: Словарь (Dictionary).
Словарь с точками для линий и их цветом. Каждая запись словаря содержит точки для полилинии и соответствующими им цветами.
Ширина (необязательный)
Тип: Число.
Ширина. Значение по умолчанию - -1.0.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует соединённые отрезки линий с равномерной шириной, поточечной раскраской и опциональным сглаживанием (поддерживается только для положительных значений ширины). Цвета, назначенные точкам линии, соответствуют индексам между точками и цветами, т.е. каждый отрезок линии заполняется градиентом между цветами конечных точек.
