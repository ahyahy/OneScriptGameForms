Кнопка.ЗетИндекс (Button.ZIndex) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает порядок, в котором отрисовывается этот узел. Узел с более высоким индексом Z будет отображаться поверх других.

Примечание

Пример

Функция Индексы() Экспорт
	Стр = 
	"Красный.ЗетИндекс = " + Кнопка1.ЗетИндекс + "
	|Синий.ЗетИндекс = " + Кнопка2.ЗетИндекс + "
	|Зеленый.ЗетИндекс = " + Кнопка3.ЗетИндекс + "
	|Васильковый.ЗетИндекс = " + Кнопка4.ЗетИндекс + "
	|ГрифельноСерый.ЗетИндекс = " + Кнопка5.ЗетИндекс + "
	|";
	Возврат Стр;
КонецФункции
