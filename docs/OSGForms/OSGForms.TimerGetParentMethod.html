Таймер.ПолучитьРодителя (Timer.GetParent) Метод

Синтаксис

ПолучитьРодителя()

Возвращаемое значение

Тип: Произвольный.

Описание

Возвращает родительский элемент данного элемента или Неопределено, если у элемента нет родителя.

Примечание

Родитель — это технический, "физический" родитель в дереве сцены. Он определяет:
- Позицию и трансформацию (если родитель двигается, ребёнок двигается вместе с ним)
- Видимость (скрыли родителя — скрылись и дети)
- Обработку событий (ввод мыши, сигналы)
- Время жизни (удалили родителя — удалились и дети)

Родитель устанавливается автоматически движком, когда вызывается метод ДобавитьДочерний (AddChild).

Пример

Сообщить("Таймер1.ПолучитьРодителя = " + Таймер1.ПолучитьРодителя());
