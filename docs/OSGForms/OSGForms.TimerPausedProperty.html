Таймер.Приостановлен (Timer.Paused) Свойство

Использование

Чтение и запись.

Значение

Тип: Булево.

Возвращает или задает флаг приостановки на паузу. Если Истина, таймер приостанавливается. Приостановленный таймер не будет выполняться, пока это свойство не будет возвращено к значению Ложь.

Примечание

Пример

Таймер1.Приостановлен = Истина;
Полный пример кода 



Перем ИФ, Таймер1, Уведомление1;

Процедура ОдноразовыйТаймер() Экспорт
	Сообщить("ОдноразовыйТаймер " + ИФ.ТекущаяДатаСМиллисекундами());
	
	Таймер1.Приостановлен = Истина;
	Сообщить("Таймер1.Приостановлен = " + Таймер1.Приостановлен);
	Приостановить(3000);
	Таймер1.Приостановлен = Ложь;
	Сообщить("Таймер1.Приостановлен = " + Таймер1.Приостановлен);
	Приостановить(2000);
	
	ИФ.СообщитьЕслиЛожь(Не Таймер1.Приостановлен
	, "Таймер.Приостановлен (Timer.Paused) Свойство");
	ИФ.Завершить();
