Библиотека OSGForms Перечисления

Перечисления

Перечисление Описание
Автоперенос (AutowrapMode) Указывает как разбивать текст и переносить на следующую строку.
ВертикальноеВыравнивание (VerticalAlignment) Указывает вертикальное выравнивание текста.
Выравнивание (AlignmentMode) Указывает режим выравнивания.
ГоризонтальноеВыравнивание (HorizontalAlignment) Указывает горизонтальное выравнивание.
ИмяСвойстваТемыВертикальнаяГруппа (NamePropertyThemeVBoxContainer) Указывает имена свойств темы для вертикальной группы.
ИмяСвойстваТемыГоризонтальнаяГруппа (NamePropertyThemeHBoxContainer) Указывает имена свойств темы для горизонтальной группы.
ИмяСвойстваТемыКнопка (NamePropertyThemeButton) Указывает имена свойств темы для кнопки.
ИмяСвойстваТемыНадпись (NamePropertyThemeLabel) Указывает имена свойств темы для надписи.
ИмяСвойстваТемыОкно (NamePropertyThemeWindow) Указывает имена свойств темы для окна.
ИмяСвойстваТемыОкноСообщений (NamePropertyThemeConfirmationDialog) Указывает имена свойств темы для окна сообщений.
ИмяСвойстваТемыПанельныйКонтейнер (NamePropertyThemePanelContainer) Указывает имена свойств темы для панельного контейнера.
ИмяСвойстваТемыУведомление (NamePropertyThemeAcceptDialog) Указывает имена свойств темы для уведомления.
Клавиши (Keys) Указывает коды клавиш.
КнопкаМыши (MouseButton) Указывает какая кнопка мыши была нажата.
МаскаКнопокМыши (MouseButtonMask) Указывает сочетание кнопок мыши как комбинированное значение при нажатии.
Модификаторы (KeyModifierMask) Указывает коды клавиш модификаторов.
Направление (Direction) Указывает направление текста.
Ориентация (Orientation) Указывает способ ориентации.
ОсевоеРастяжение (AxisStretchMode) Указывает растяжение или расположение объекта по осям.
ПоведениеПриПереполнении (OverrunBehavior) Указывает поведение обрезки, когда текст выходит за пределы ограничивающего прямоугольника узла.
РежимОтрисовки (DrawMode) Указывает визуальное состояние, используемое для отрисовки кнопки.
РежимСглаживания (MSAA) Указывает варианты сглаживания на краях геометрических объектов.
РежимФокусировки (FocusMode) Указывает возможности захвата фокуса узлом.
СистемныйКаталог (SystemDir) Указывает перечислимые константы, используемые для получения путей к системным каталогам.
ТипЭлементаТемы (ThemeDataType) Указывает тип элемента темы.
ФлагВыравниванияПоШирине (JustificationFlag) Указывает способ выравнивания текста по ширине.
ФлагиРазмера (SizeFlags) Указывает набор битовых флагов, определяющих поведение узла интерфейса (Контрол) внутри своего контейнера-родителя.
ФлагПереносаСтроки (LineBreakFlag) Указывает способ разделения текста для переноса.
ФорматИзображения (ImageFormat) Указывает формат файла изображения.
