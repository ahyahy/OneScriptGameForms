Графика.РисоватьМногострочныйТекст (Graphics.DrawMultilineString) Метод

Синтаксис

РисоватьМногострочныйТекст(<Шрифт>, <Позиция>, <Текст>, <Выравнивание>, <Ширина>, <РазмерШрифта>, <МаксимальноеЧислоЛиний>, <ИзменениеЦвета>, <Разделение>, <ВыравниваниеПоШирине>, <Направление>, <Ориентация>, <ДискретноеПреобразование>)

Параметры

Шрифт (обязательный)
Тип: Произвольный.
Шрифт нарисованного текста.
Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция текста.
Текст (обязательный)
Тип: Строка.
Текст для отрисовки.
Выравнивание (необязательный)
Тип: ГоризонтальноеВыравнивание (HorizontalAlignment).
Выравнивание текста. Значение по умолчанию - Лево (Left).
Ширина (необязательный)
Тип: Число.
Ширина. Расстояние между границами, в которые будет помещен текст. Значение по умолчанию - -1.
РазмерШрифта (необязательный)
Тип: Число.
Размер шрифта. Значение по умолчанию - 16.
МаксимальноеЧислоЛиний (необязательный)
Тип: Число.
Максимальное число линий. Значение по умолчанию - -1.
ИзменениеЦвета (необязательный)
Тип: Цвет (Color).
Модуляция цвета. Значение по умолчанию - Белый.
Разделение (необязательный)
Тип: ФлагПереносаСтроки (LineBreakFlag).
Способ разделения текста для переноса. Значение по умолчанию - Обязательно (Mandatory) + ГраницаСлов (WordBound).
ВыравниваниеПоШирине (необязательный)
Тип: ФлагВыравниванияПоШирине (JustificationFlag).
Способ выравнивания текста по ширине. Значение по умолчанию - Кашида (Kashida) + ГраницаСлов (WordBound).
Направление (необязательный)
Тип: Направление (Direction).
Направление текста.
Ориентация (необязательный)
Тип: Ориентация (Orientation).
Ориентация по осям икс, игрек, зет.
ДискретноеПреобразование (необязательный)
Тип: Число.
Если параметр больше нуля, он используется как коэффициент передискретизации шрифта, в противном случае используются настройки передискретизации области просмотра. Значение по умолчанию - 0.

Возвращаемое значение

Описание

Разбивает текст на строки и рисует их указанным шрифтом.

Примечание

Пример

ШрифтВариативный3 = ИФ.ШрифтВариативный(ОбъединитьПути(ТекущийСценарий().Каталог, "times.ttf"));
Графика1.РисоватьМногострочныйТекст(ШрифтВариативный3, ИФ.Вектор2(5, 30), "Графика1 Рисовать Многострочный Текст Рисовать Многострочный Текст", 0, 500, 42, 3, Иф.Цвет.Синий);
