ТемаКнопка (ThemeButton) Свойства

Свойства

ВыровнятьПоНаибольшимПолям (AlignToLargestStylebox) Возвращает или задает константу, которая действует как логическое значение. Если Истина, минимальный размер кнопки и выравнивание текста или значка всегда основаны на самых больших полях стиля панели, в противном случае они основаны на полях стиля панели текущего состояния кнопки. Значение по умолчанию - 0.
ГоризонтальноеРазделение (HSeparation) Возвращает или задает горизонтальное пространство между значком кнопки и текстом. Отрицательные значения будут рассматриваться как 0 при использовании. Значение по умолчанию - 4.
Значок (Icon) Возвращает или задает значок по умолчанию для кнопки. Появляется только если значок не назначен.
ИмяРесурса (ResourceName) (унаследовано от Ресурс (Resource)) Необязательное имя для этого ресурса. Значение по умолчанию - "ThemeButton".
КлючЭлемента (ItemKey) (унаследовано от ОбъектГодо (GObject)) Возвращает уникальный ключ элемента сгенерированный при создании.
МаксимальнаяШиринаЗначка (IconMaxWidth) Возвращает или задает максимально допустимую ширину значка кнопки. Это ограничение применяется поверх размера значка по умолчанию или его расширенного размера, если ExpandIcon равно Истина. Высота регулируется в соответствии с соотношением значка. Если у кнопки есть дополнительные значки (например, флажок), они также будут ограничены. Значение по умолчанию - 0.
МасштабПоУмолчанию (DefaultBaseScale) (унаследовано от Тема (Theme)) Возвращает или задает базовый масштабный коэффициент по умолчанию для этого ресурса темы. Используется некоторыми элементами управления для масштабирования их визуальных свойств на основе глобального масштабного коэффициента. Если это значение установлено на 0.0, используется глобальный масштабный коэффициент. Значение по умолчанию - 0.0.
МежстрочныйИнтервал (LineSpacing) Возвращает или задает дополнительный вертикальный интервал между строками (в пикселях), интервал добавляется к спуску строки. Это значение может быть отрицательным. Значение по умолчанию - 0.
Метка (Tag) (унаследовано от ОбъектГодо (GObject)) Возвращает или задает объект, содержащий дополнительные данные.
ПриНаведении (Hover) Возвращает или задает стиль панели при наведении курсора на кнопку.
ПриНаведенииЗеркальное (HoverMirrored) Возвращает или задает стиль панели при наведении курсора на кнопку (для макетов с направлением справа налево).
ПриНаведенииПриНажатии (HoverPressed) Возвращает или задает стиль панели, когда кнопка нажата и одновременно находится под курсором.
ПриНаведенииПриНажатииЗеркальное (HoverPressedMirrored) Возвращает или задает стиль панели при одновременном нажатии и наведении курсора на кнопку (для макетов с направлением справа налево).
ПриНажатии (Pressed) Возвращает или задает стиль панели, используемый при нажатии кнопки.
ПриНажатииЗеркальное (PressedMirrored) Возвращает или задает стиль панели, используемый при нажатии кнопки (для макетов с направлением справа налево).
ПриОтключении (Disabled) Возвращает или задает стиль панели, когда кнопка отключена.
ПриОтключенииЗеркальное (DisabledMirrored) Возвращает или задает стиль панели, когда кнопка отключена (для макетов текста справа налево).
ПриФокусировке (Focus) Возвращает или задает стиль панели, когда кнопка находится в фокусе. Свойство элемента ПриФокусировке (Focus) отображается над базовым стилем панели, поэтому следует использовать частично прозрачный стиль панели, чтобы базовый стиль панели оставался видимым. Стиль панели, представляющий контур или подчеркивание, хорошо подходит для этой цели. Чтобы отключить визуальный эффект фокуса, назначьте ресурс СтильПанелиПусто (StyleBoxEmpty). Обратите внимание, что отключение визуального эффекта фокуса навредит удобству использования навигации с помощью клавиатуры, поэтому это не рекомендуется по соображениям доступности.
ПутьРесурса (ResourcePath) (унаследовано от Ресурс (Resource)) Возвращает или задает уникальный путь к этому ресурсу. Если он был сохранен на диске, значением будет его путь к файлу.
РазмерКонтура (OutlineSize) Возвращает или задает размер контура текста. Значение по умолчанию - 0.
РазмерШрифта (FontSize) Возвращает или задает размер шрифта текста кнопки.
РазмерШрифтаПоУмолчанию (DefaultFontSize) (унаследовано от Тема (Theme)) Возвращает или задает размер шрифта по умолчанию для этого ресурса темы. Используется как значение по умолчанию при попытке получить значение размера шрифта, которого нет в этой теме или которое находится в недопустимом состоянии. Если размер шрифта по умолчанию также отсутствует или недопустим, используется резервное значение движка. Значения ниже 1 недействительны и могут использоваться для сброса свойства. Значение по умолчанию - -1.
Стандартное (Normal) Возвращает или задает стиль панели по умолчанию для кнопки.
СтандартноеЗеркальное (NormalMirrored) Возвращает или задает стиль панели по умолчанию для кнопки (для макетов справа налево).
ЦветЗначкаПриНаведении (IconHoverColor) Возвращает или задает цвет значка, используемый при наведении курсора на кнопку.
ЦветЗначкаПриНаведенииПриНажатии (IconHoverPressedColor) Возвращает или задает цвет значка, используемый при наведении и нажатии кнопки.
ЦветЗначкаПриНажатии (IconPressedColor) Возвращает или задает цвет значка, используемый при нажатии кнопки.
ЦветЗначкаПриОтключении (IconDisabledColor) Возвращает или задает цвет значка, когда кнопка отключена.
ЦветЗначкаПриФокусировке (IconFocusColor) Возвращает или задает цвет значка, когда кнопка находится в фокусе. Заменяет только обычный цвет кнопки. Отключенные, наведенные и нажатые состояния имеют приоритет над этим цветом.
ЦветЗначкаСтандартное (IconNormalColor) Возвращает или задает цвет значка кнопки по умолчанию.
ЦветКонтураШрифта (FontOutlineColor) Возвращает или задает оттенок контура текста кнопки.
ЦветШрифта (FontColor) Возвращает или задает цвет текста по умолчанию.
ЦветШрифтаПриНаведении (FontHoverColor) Возвращает или задает цвет текста, используемый при наведении курсора на кнопку.
ЦветШрифтаПриНаведенииПриНажатии (FontHoverPressedColor) Возвращает или задает цвет текста, используемый при наведении и нажатии кнопки.
ЦветШрифтаПриНажатии (FontPressedColor) Возвращает или задает цвет текста, используемый при нажатии кнопки.
ЦветШрифтаПриОтключении (FontDisabledColor) Возвращает или задает цвет текста, когда кнопка отключена.
ЦветШрифтаПриФокусировке (FontFocusColor) Возвращает или задает цвет текста, используемый, когда кнопка находится в фокусе. Заменяет только обычный цвет текста кнопки. Отключенные, наведенные и нажатые состояния имеют приоритет над этим цветом.
Шрифт (Font) Возвращает или задает шрифт текста кнопки.
ШрифтПоУмолчанию (DefaultFont) (унаследовано от Тема (Theme)) Возвращает или задает шрифт по умолчанию этого ресурса темы. Используется как значение по умолчанию при попытке получить ресурс шрифта, который не существует в этой теме или находится в недопустимом состоянии. Если шрифт по умолчанию также отсутствует или недопустим, используется резервное значение движка.
