ТемаСцена.УстановитьЦвет (ThemeScene.SetColor) Метод

Синтаксис

УстановитьЦвет(<ИмяСвойстваТемы>, <Цвет>)

Параметры

ИмяСвойстваТемы (обязательный)
Тип: Произвольный.
Одно из значений перечисления, содержащего имена свойств темы для соответствующего типа узла.
Цвет (обязательный)
Тип: Цвет (Color).
Устанавливаемое значение цвета.

Возвращаемое значение

Описание

Создает или изменяет значение свойства темы.

Примечание

Пример

ТемаСцена1.УстановитьЦвет(Иф.ИмяСвойстваТемыНадпись.ЦветШрифта, Иф.Цвет.Синий);
