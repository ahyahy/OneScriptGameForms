ТемаОкно (ThemeWindow) Свойства

Свойства

ВнедреннаяГраница (EmbeddedBorder) Возвращает или задает стиль панели, используемый при внедрении окна. Фон содержимого не будет виден, если не включен параметр transparent.
ВнедреннаяНеСфокусированнаяГраница (EmbeddedUnfocusedBorder) Возвращает или задает стиль панели, используемый, когда окно встроено и не сфокусировано.
ВысотаЗаголовка (TitleHeight) Возвращает или задает высоту строки заголовка. Значение по умолчанию - 36.
ЗначокЗакрытия (Close) Возвращает или задает значок кнопки закрытия.
ЗначокЗакрытияПриНажатии (ClosePressed) Возвращает или задает значок кнопки закрытия при нажатии.
ИмяРесурса (ResourceName) (унаследовано от Ресурс (Resource)) Необязательное имя для этого ресурса. Значение по умолчанию - "ThemeWindow".
КлючЭлемента (ItemKey) (унаследовано от ОбъектГодо (GObject)) Возвращает уникальный ключ элемента сгенерированный при создании.
МасштабПоУмолчанию (DefaultBaseScale) (унаследовано от Тема (Theme)) Возвращает или задает базовый масштабный коэффициент по умолчанию для этого ресурса темы. Используется некоторыми элементами управления для масштабирования их визуальных свойств на основе глобального масштабного коэффициента. Если это значение установлено на 0.0, используется глобальный масштабный коэффициент. Значение по умолчанию - 0.0.
Метка (Tag) (унаследовано от ОбъектГодо (GObject)) Возвращает или задает объект, содержащий дополнительные данные.
ПутьРесурса (ResourcePath) (унаследовано от Ресурс (Resource)) Возвращает или задает уникальный путь к этому ресурсу. Если он был сохранен на диске, значением будет его путь к файлу.
РазмерКонтураЗаголовка (TitleOutlineSize) Возвращает или задает размер контура заголовка. Значение по умолчанию - 0.
РазмерШрифтаЗаголовка (TitleFontSize) Возвращает или задает размер шрифта заголовка.
РазмерШрифтаПоУмолчанию (DefaultFontSize) (унаследовано от Тема (Theme)) Возвращает или задает размер шрифта по умолчанию для этого ресурса темы. Используется как значение по умолчанию при попытке получить значение размера шрифта, которого нет в этой теме или которое находится в недопустимом состоянии. Если размер шрифта по умолчанию также отсутствует или недопустим, используется резервное значение движка. Значения ниже 1 недействительны и могут использоваться для сброса свойства. Значение по умолчанию - -1.
СмещениеЗахвата (ResizeMargin) Возвращает или задает внешнее поле, за которое можно захватить границу окна мышью и изменить ее размер. Значение по умолчанию - 4.
СмещениеКнопкиЗакрытияИгрек (CloseVOffset) Возвращает или задает смещение вертикального положения кнопки закрытия относительно нижней части строки заголовка по направлению к верхней части строки заголовка. Значение по умолчанию - 24.
СмещениеКнопкиЗакрытияИкс (CloseHOffset) Возвращает или задает горизонтальное смещение положения кнопки закрытия относительно конца строки заголовка в сторону начала строки заголовка. Значение по умолчанию - 18.
ЦветЗаголовка (TitleColor) Возвращает или задает цвет текста заголовка.
ЦветКонтураЗаголовка (TitleOutlineModulate) Возвращает или задает цвет контура текста заголовка.
ШрифтЗаголовка (TitleFont) Возвращает или задает шрифт, используемый для заголовка.
ШрифтПоУмолчанию (DefaultFont) (унаследовано от Тема (Theme)) Возвращает или задает шрифт по умолчанию этого ресурса темы. Используется как значение по умолчанию при попытке получить ресурс шрифта, который не существует в этой теме или находится в недопустимом состоянии. Если шрифт по умолчанию также отсутствует или недопустим, используется резервное значение движка.
