Использование

Чтение и запись.

Значение

Тип: РежимФокусировки (FocusMode).

Возвращает или задает способ получения элементом управления фокуса. Только один элемент управления может быть сфокусирован одновременно. Значение по умолчанию - Отсутствие (None).
