Текстура (Texture) Класс

Описание

Базовый класс для всех типов текстур.

Это абстрактный базовый ресурс, представляющий собой двумерное изображение, которое может быть использовано для отрисовки в игре. Сам по себе этот класс не хранит пиксели и не используется напрямую; он служит общим интерфейсом для всех типов изображений в движке. Когда вы видите свойство типа Текстура (Texture) (например, текстура у Спрайт2д или текстура у кнопки), это означает, что туда можно поместить любой конкретный тип изображения: статичную картинку, атлас спрайтов, процедурное изображение или даже результат рендеринга камеры.

Основные возможности

Универсальность
  • Позволяет использовать разные типы изображений в одних и тех же местах кода.
    • Поддержка различных форматов
  • Через наследников поддерживает растровые изображения (PNG, JPG, WebP), атласы шрифтов и спрайтов, а также динамические буферы.
