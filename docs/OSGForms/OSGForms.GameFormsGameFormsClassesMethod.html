КлассыИгровыхФорм()

Возвращаемое значение

Тип: Строка.

Многострочная строка с перечнем основных классов библиотеки игровых форм.

Описание

Возвращает многострочную строку с перечнем основных классов библиотеки игровых форм.

Примечание

Метод создан для оптимизации тестирования библиотеки.

Пример

Стр1 = ИФ.КлассыИгровыхФорм();
Сообщить("" + Стр1);
