АнимированныйСпрайт2д (AnimatedSprite2D) Класс

Описание

Представляет узел спрайта, содержащий несколько текстур в качестве кадров для анимации.

Это специализированный узел для отображения и управления 2D-анимациями, основанный на спрайтовых листах (sprite sheets) или наборах отдельных текстур. В отличие от обычного Спрайт2д (Sprite2D), который отображает статичное изображение (или требует ручного кодинга для смены кадров), АнимированныйСпрайт2д (AnimatedSprite2D) имеет встроенный движок анимации. Он хранит набор анимаций (например, "праздный", "бег", "прыжок"), каждая из которых состоит из последовательности кадров, и автоматически переключает их с заданной скоростью. Этот узел является стандартом де-факто для анимации персонажей, врагов, эффектов и объектов окружения в 2D-играх на Godot.

Основные возможности

Управление библиотекой анимаций
  • Позволяет хранить множество различных анимаций в одном узле. Вы можете переключаться между ними программно (например, сменить анимацию с "бега" на "прыжок" одной командой).
    • Работа со спрайтовыми листами (Atlas)
  • Использует ресурс БиблиотекаКадров (SpriteFrames), который описывает, как нарезать большую текстуру-атлас на кадры. Вы задаете количество кадров по горизонтали и вертикали, а движок сам вычисляет координаты каждого кадра.
    • Автоматическое воспроизведение
  • Поддерживает настройки скорости (FPS), зацикливания и однократного воспроизведения. Анимация обновляется автоматически каждый кадр.
    • События анимации
  • Позволяет привязывать события к конкретным кадрам (например, звук шага или момент нанесения урона), которые срабатывают автоматически в нужный момент воспроизведения.
