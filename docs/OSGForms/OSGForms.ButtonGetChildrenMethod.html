Кнопка.ПолучитьДочерние (Button.GetChildren) Метод

Синтаксис

ПолучитьДочерние()

Возвращаемое значение

Тип: Массив.

Описание

Возвращает все дочерние элементы этого узла.

Примечание

Пример

Дочерние = Кнопка1.ПолучитьДочерние();
