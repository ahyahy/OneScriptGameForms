ПанельныйКонтейнер.ПолучитьСтильПанелиПлоский (PanelContainer.GetThemeStyleboxFlat) Метод

Синтаксис

ПолучитьСтильПанелиПлоский(<ИмяСвойстваТемыДляКонтрола>)

Параметры

ИмяСвойстваТемыДляКонтрола (обязательный)
Тип: Произвольный.
Одно из значений перечисления ИмяСвойстваТемы... для контрола.

Возвращаемое значение

Тип: СтильПанелиПлоский (StyleBoxFlat).

Стиль панели для всех экземпляров этого класса.

Описание

Возвращает объект СтильПанелиПлоский (StyleBoxFlat) с указанным именем стиля. Имя стиля - это Одно из значений перечисления ИмяСвойстваТемы... для контрола.

Примечание

Возвращает запрошенный тип стиля из первой соответствующей темы в дереве, если эта тема имеет стиль такого типа. В противном случае будет создан новый экземпляр стиля запрошенного типа.

Пример

СтильПоУмолчанию = ПанельныйКонтейнер1.ПолучитьСтильПанелиПлоский(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель);
