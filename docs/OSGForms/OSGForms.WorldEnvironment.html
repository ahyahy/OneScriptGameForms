ОкружениеМира (WorldEnvironment) Класс

Описание

Представляет свойства среды по умолчанию для всей сцены (эффекты постобработки, настройки освещения и фона).

Это узел сцены, который управляет глобальными настройками окружающей среды и пост-обработки для всей 3D-сцены (или для той её части, где расположен этот узел).

Основные возможности

Настройки окружения
  • Фон: Определяет, что видно на заднем плане (сплошной цвет, градиент, панорамное небо или процедурное небо).
  • Освещение: Настраивает фоновый свет, который освещает тени, и энергию неба.
  • Туман: Добавляет атмосферную дымку, скрывающую дальние объекты или создающую настроение (линейный, экспоненциальный, высотный туман).
    • Эффекты пост-обработки (Post-Processing)
  • Это фильтры, которые применяются к уже отрендеренному изображению перед выводом на экран. WorldEnvironment позволяет включить и настроить:
  • SSAO: Затенение в углах и стыках объектов для объема.
  • SSIL: Имитация отраженного света.
  • Glow: Эффект свечения для ярких участков изображения.
  • DOF: Размытие фона (эффект боке) в зависимости от расстояния до камеры.
  • Tonemapping: Коррекция цветов и яркости для реалистичного отображения (ACES, Reinhard и др.).
  • Vignette, Color Correction, Brightness/Contrast: Художественная цветокоррекция.
