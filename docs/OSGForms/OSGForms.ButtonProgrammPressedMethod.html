Кнопка.ПрограммноНажать (Button.ProgrammPressed) Метод

Синтаксис

ПрограммноНажать()

Возвращаемое значение

Описание

Выполняет программное нажатие кнопки. Нажатие равнозначно щелчку левой кнопки мыши в точке соответствующей позиции кнопки.

Примечание

Пример

Кнопка1.ПрограммноНажать();
Полный пример кода 



Перем ИФ, Кнопка1;

	Сообщить("Кнопка1_Нажатие " + ТекущаяУниверсальнаяДатаВМиллисекундах());
	ИФ.СообщитьЕслиЛожь(Не Кнопка1.КлючЭлемента = "", "Кнопка.ПрограммноНажать (Button.ProgrammPressed) Метод");
	ИФ.Завершить();
