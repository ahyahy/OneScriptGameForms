ТемаСцена.ОчиститьЦвет (ThemeScene.ClearColor) Метод

Синтаксис

ОчиститьЦвет(<ИмяСвойстваТемы>)

Параметры

ИмяСвойстваТемы (обязательный)
Тип: Произвольный.
Одно из значений перечисления, содержащего имена свойств темы для соответствующего типа узла.

Возвращаемое значение

Описание

Удаляет свойство цвета, если оно существует. Не выполняется, если свойство не существует.

Примечание

Пример

ТемаСцена1.ОчиститьЦвет(Иф.ИмяСвойстваТемыНадпись.ЦветШрифта);
