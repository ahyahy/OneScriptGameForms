ТемаСцена (ThemeScene) Методы

Методы

ВСтроку (ToString) (унаследовано от ОбъектГодо (GObject)) Возвращает строковое представление данного объекта.
Дублировать (Duplicate) (унаследовано от Ресурс (Resource)) Дублирует этот ресурс, возвращая новый ресурс со свойствами, скопированными из исходного.
Очистить (Clear) (унаследовано от Тема (Theme)) Удаляет все свойства темы, определенные в ресурсе темы.
ОчиститьЗначок (ClearIcon) Удаляет свойство значка, если оно существует. Не выполняется, если свойство не существует.
ОчиститьКонстанту (ClearConstant) Удаляет константное свойство, если оно существует. Не выполняется, если свойство не существует.
ОчиститьРазмерШрифта (ClearFontSize) Удаляет свойство размера шрифта, если оно существует. Не выполняется, если свойство не существует.
ОчиститьСтильПанели (ClearStylebox) Удаляет свойство стиля панели, если оно существует. Не выполняется, если свойство не существует.
ОчиститьЦвет (ClearColor) Удаляет свойство цвета, если оно существует. Не выполняется, если свойство не существует.
ОчиститьШрифт (ClearFont) Удаляет свойство шрифта, если оно существует. Не выполняется, если свойство не существует.
ПолучитьЗначок (GetIcon) Возвращает значок для свойства темы, если он существует. Возвращает значение значка резервного движка, если свойство не существует.
ПолучитьКонстанту (GetConstant) Возвращает константное свойство, если оно существует.
ПолучитьРазмерШрифта (GetFontSize) Возвращает размера шрифта для свойства темы, если он существует. Возвращает размер шрифта темы по умолчанию, если свойство не существует и размер шрифта темы по умолчанию установлен. Возвращает значение резервного размера шрифта движка, если ни то, ни другое не существует.
ПолучитьСтильПанели (GetStylebox) Возвращает стиль панели для свойства, если оно существует. Возвращает резервное значение стиля панели движка, если свойство не существует.
ПолучитьЦвет (GetColor) Возвращает цвет для свойства темы, если оно существует. Возвращает значение цвета по умолчанию, если свойство не существует.
ПолучитьШрифт (GetFont) Возвращает шрифт для свойства темы, если он существует. Возвращает шрифт темы по умолчанию, если свойство не существует и шрифт темы по умолчанию установлен. Возвращает значение резервного шрифта движка, если ни один из них не существует.
Сохранить (Save) (унаследовано от Ресурс (Resource)) Сохраняет ресурс на диске по указанному пути.
УстановитьЗначок (SetIcon) Создает или изменяет значение свойства темы.
УстановитьКонстанту (SetConstant) Создает или изменяет значение константного свойства.
УстановитьРазмерШрифта (SetFontSize) Создает или изменяет значение свойства темы.
УстановитьСтильПанели (SetStylebox) Создает или изменяет значение свойства темы.
УстановитьЦвет (SetColor) Создает или изменяет значение свойства темы.
УстановитьШрифт (SetFont) Создает или изменяет значение свойства темы.
