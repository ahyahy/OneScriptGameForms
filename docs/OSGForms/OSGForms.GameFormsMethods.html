ИгровыеФормы (GameForms) Методы

Методы

[Перечисление].Значение ([Перечисление].Value) Возвращает значение элемента перечисления по его имени.
[Перечисление].Имя ([Перечисление].Name) Возвращает строковое представление значения перечисления.
[Перечисление].Количество ([Перечисление].Count) Возвращает количество элементов в перечислении.
[Перечисление].Получить ([Перечисление].Get) Возвращает элемент перечисления по индексу.
Выполнить (Execute) Вызывает заданный метод.
ДобавитьВесьТекст (AppendAllText) Открывает файл, добавляет указанную строку в файл, а затем закрывает файл. Если файл не существует, этот метод создает файл, записывает указанную строку в файл, а затем закрывает файл. Метод создан для оптимизации тестирования.
Завершить (Shutdown) Завершает приложение Godot.
Загрузить (Load) Загружает ресурс по указанному пути.
ЗагрузитьМодель (LoadModel) Загружает 3D модель.
Запустить (Run) Запускает приложение Godot.
КаталогСценария (DirectoryScenario) Возвращает каталог переданного в параметре сценария.
КлассыИгровыхФорм (GameFormsClasses) Возвращает многострочную строку с перечнем основных классов библиотеки игровых форм.
МассивИменЦветов (ColorNameArray) Возвращает массив имен цветов.
НайтиЦентр (FindCenter) Возвращает объект Вектор2 (Vector2) соответствующий центру переданного в параметре объекта, в координатах относительно родителя.
НовыйОбъект (NewObject) Возвращает экземпляр класса по имени, переданном в параметре.
НормализоватьПуть (NormalizedPath) Возвращает путь, приведенный к формату, поддерживаемому движком Годо. Годо поддерживает только / в качестве разделителя путей.
НотацияЗмеинуюВПаскаля (SnakeCaseToPascalCase) Возвращает строку - имя в нотации "Паскаля".
НотацияПаскаляВЗмеиную (PascalCaseToSnakeCase) Возвращает строку - имя в нотации "Змеиная".
ОдноразовыйТаймер (SceneTreeTimer) Создает событие после заданного интервала, без возможности повторения.
ОжидатьФайл (WaitFile) Возвращает результат проверки существования файла на диске, с задержкой в миллисекундах на ожидание при проверке.
ОтправитьКлавишуКонсоли (SendConsoleKey) Отправляет клавишу консоли без использования клавиатуры.
ПереместитьМышь (WarpMouse) Перемещает курсор мыши в новую позицию.
ПолучитьКодСценария (GetScriptCode) Возвращает код переданного в параметре сценария.
ПолучитьПозициюМыши (GetMousePosition) Возвращает положение мыши.
ПолучитьСистемныйКаталог (GetSystemDir) Возвращает путь к одному из системных каталогов.
ПолучитьСнимок (GetSnapshot) Возвращает объект Изображение (Image), который представляет собой снимок окна, которому принадлежит узел.
ПолучитьТекстБуфераОбмена (ClipboardGet) Возвращает буфер обмена пользователя в виде строки, если это возможно.
ПроброситьИсключение (SkipException) Вызывает событие при котором в консоль выводится строка, переданная в параметре. После этого приложение игровые формы завершаются. После этого завершается работа сценария с кодом возврата равным 1. Метод создан для оптимизации тестирования.
ПрограммныйКлик (ProgramClick) Выполняет программное нажатие на кнопку мыши.
ПутьСценария (PathScenario) Возвращает путь до переданного в параметре сценария.
СвойстваИЗначения (PropertiesAndValues) Возвращает многострочную строку с перечнем свойств в русскоязычном и англоязычном вариантах переданного в параметре объекта. Так же выводятся текущие значения свойств.
СообщитьЕслиЛожь (ReportIfFalse) Выводит заключенный в фигурные скобки текст, переданный в параметре Сообщение, если условие, переданное в параметре Условие возвратит Ложь. Метод создан для оптимизации тестирования.
СтрНайтиМежду (StrFindBetween) Поиск в заданном тексте участков, ограниченных параметрами Фрагмент1 и Фрагмент2. Метод возвращает массив из строк, ограниченных параметрами Фрагмент1 и Фрагмент2.
ТекущаяДатаСМиллисекундами (CurrentDateWithMilliseconds) Возвращает строку с текущей (системной) датой на компьютере с миллисекундами до седьмого знака.
УдалитьЭлемент (RemoveElement) Удаляет переданный в параметре элемент.
УстановитьТекстБуфераОбмена (ClipboardSet) Устанавливает содержимое буфера обмена пользователя в соответствии с заданной строкой.
