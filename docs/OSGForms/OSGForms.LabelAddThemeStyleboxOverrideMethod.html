Надпись.ДобавитьСтиль (Label.AddThemeStyleboxOverride) Метод

Синтаксис

ДобавитьСтиль(<ИмяСвойстваТемы>, <СтильПанели>)

Параметры

ИмяСвойстваТемы (обязательный)
Тип: Произвольный.
Одно из значений перечисления имен свойств темы для соответствующего элемента.
СтильПанели (обязательный)
Тип: Произвольный.
Пользовательский стиль, которым будет переопределен стиль по умолчанию.

Возвращаемое значение

Описание

Создает локальное переопределение для стиля элемента. Локальные переопределения всегда имеют приоритет перед стилем по умолчанию. Переопределение можно удалить с помощью метода УдалитьСтиль (RemoveThemeStyleboxOverride).

Примечание

Пример

СтильПанелиПлоский1 = Иф.СтильПанелиПлоский();
СтильПанелиПлоский1.ЦветФона = ИФ.Цвет.НебесноГолубой;
Надпись1.ДобавитьСтиль(ИФ.ИмяСвойстваТемыНадпись.Стандартное, СтильПанелиПлоский1);
