Модификаторы (KeyModifierMask) Перечисление

Описание

Указывает коды клавиш модификаторов.

Это набор битовых флагов, представляющих состояние клавиш-модификаторов (Shift, Ctrl, Alt, Meta/Cmd) в момент события ввода. В отличие от обычных клавиш, модификаторы редко используются сами по себе; их главная задача - изменять действие других клавиш (например, Ctrl+C для копирования или Shift+Стрелка для выделения текста). Это перечисление позволяет компактно хранить и проверять состояние всех модификаторов одновременно в одном целом числе, что критически важно для реализации горячих клавиш (шорткатов) и кроссплатформенного управления.

Члены

Имя члена Описание Значение
Alt (Alt) Маска клавиш Alr или Option (на macOS). 67108864
Code (Code) Битовая маска со всеми включенными битами, кроме клавиш-модификаторов. Примените её для удаления модификаторов. Применив её вы получите код клавиши. 8388607
Ctrl (Ctrl) Маска управляющей клавиши. 268435456
GroupSwitch (GroupSwitch) Маска клавиш группового переключателя. 1073741824
Kpad (Kpad) Маска клавиш цифровой клавиатуры. 536870912
Modifier (Modifier) Битовая маска со всеми включенными битами модификаторов. Примените её для изоляции модификаторов. Применив её вы получите код модификаторов. 2130706432
None (None) Значение перечисления, которые не соответствует ни одному ключу. 0
Shift (Shift) Маска клавиши Shift. 33554432
Meta (Meta) Маска клавиш Command (на macOS) или Meta (на Windows). 134217728
