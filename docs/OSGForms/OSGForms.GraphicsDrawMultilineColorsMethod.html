Графика.РисоватьЦветнуюМультилинию (Graphics.DrawMultilineColors) Метод

Синтаксис

РисоватьЦветнуюМультилинию(<СловарьЛинийЦветов>, <Ширина>, <Сглаживание>)

Параметры

СловарьЛинийЦветов (обязательный)
Тип: Словарь (Dictionary).
Словарь с точками для линий и их цветом. Каждая запись словаря содержит точки начала и конца линии и соответствующий ей цвет.
Ширина (необязательный)
Тип: Число.
Ширина. Значение по умолчанию - -1.0.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует несколько разрозненных линий с равномерной шириной и посегментной раскраской. Каждый сегмент определяется двумя последовательными точками и соответствующим цветом в параметре СловарьЛинийЦветов, т.е. i-й сегмент состоит из points[2 * i], points[2 * i + 1] конечных точек и имеет цвет colors[i].

Примечание

Пример

Графика1 = ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.Графика());
Словарь3 = ИФ.Словарь();

Словарь3.Добавить(ИФ.Запись(ИФ.Вектор2(260, 306), ИФ.Вектор2(288, 330)), Иф.Цвет.ГлубокийРозовый);
Словарь3.Добавить(ИФ.Запись(ИФ.Вектор2(278, 320), ИФ.Вектор2(300, 250)), Иф.Цвет.Красный);
Словарь3.Добавить(ИФ.Запись(ИФ.Вектор2(300, 270), ИФ.Вектор2(350, 230)), Иф.Цвет.Синий);
Графика1.РисоватьЦветнуюМультилинию(Словарь3, 5);
