ОсевоеРастяжение (AxisStretchMode) Перечисление

Описание

Указывает растяжение или расположение объекта по осям.

Это набор констант, определяющих поведение текстуры (или её части) при изменении размера области отрисовки вдоль конкретной оси (горизонтальной или вертикальной). Оно указывает движку, как именно заполнять пространство: растягивать всё изображение, повторять его (тайлить), оставлять размер неизменным или использовать умное масштабирование с сохранением пропорций важных участков (9-patch).

Члены

Имя члена Описание Значение
Вписать (Fit) Повторяет текстуру стиля панели для соответствия размеру стиля панели в соответствии с системой из девяти частей. В отличие от Плитка (Tile), текстура может быть слегка растянута, чтобы сделать текстуру из девяти частей бесшовной. 2
Плитка (Tile) Повторяет текстуру стиля панели, чтобы она соответствовала размеру стиля панели в соответствии с системой девяти частей. 1
Растянуть (Stretch) Растянуть текстуру стиля панели. Это приведет к видимым искажениям, если только размер текстуры не будет идеально соответствовать размеру стиля панели. 0
