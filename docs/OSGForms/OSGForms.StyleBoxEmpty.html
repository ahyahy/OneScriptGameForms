СтильПанелиПусто (StyleBoxEmpty) Класс

Описание

Пустой стиль рамки, который можно использовать для отображения ничего вместо стиля по умолчанию.

Это специальный ресурс оформления, который ничего не рисует и не имеет внутренних отступов. Это невидимый стиль, используемый для того, чтобы убрать стандартный фон у элемента интерфейса, сохранив при этом его функциональность (клики, фокус, расположение текста). В отличие от других стилей, у него нет свойств цвета, текстуры, толщины рамки или скругления, так как его единственная задача - быть абсолютно прозрачным и не занимать лишнего места.

Основные возможности

Полная прозрачность
  • Не отрисовывает ни цвета, ни градиентов, ни рамок, ни теней. Элемент с этим стилем становится визуально невидимым (остается только его содержимое: текст, иконки).
    • Нулевые отступы
  • Внутренние отступы по умолчанию равны нулю. Это позволяет содержимому (например, тексту кнопки) занимать всю доступную площадь элемента, не сдвигаясь внутрь.
    • Сброс стандартного оформления
  • Часто используется для переопределения стилей в теме. Например, если вы хотите, чтобы кнопка выглядела просто как текст без рамки, вы назначаете ей СтильПанелиПусто (StyleBoxEmpty) для состояния Стандартное (Normal).
    • Производительность
  • Самый легкий стиль для рендеринга, так как движок просто пропускает этап отрисовки фона для этого элемента.
