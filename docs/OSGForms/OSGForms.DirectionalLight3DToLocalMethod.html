НаправленныйСвет3д.ВЛокальные (DirectionalLight3D.ToLocal) Метод

Синтаксис

ВЛокальные(<ГлобальнаяТочка>)

Параметры

ГлобальнаяТочка (обязательный)
Тип: Вектор3 (Vector3).
Точка в мировых координатах сцены.

Возвращаемое значение

Тип: Вектор3 (Vector3).

Координаты этой точки в локальном пространстве текущего узла.

Описание

Возвращает локальную точку, преобразованную из глобального пространства в локальное пространство этого узла.
