СтильПанелиТекстура.УстановитьВылетТекстурыВсех (StyleBoxTexture.SetTextureMarginAll) Метод

Синтаксис

УстановитьВылетТекстурыВсех(<ВылетТекстуры>)

Параметры

ВылетТекстуры (обязательный)
Тип: Число.

Возвращаемое значение

Описание

Устанавливает поле текстуры на указанное количество пикселей для всех сторон.

Примечание

Пример

СтильПанелиТекстура1.УстановитьВылетТекстурыВсех(50);
