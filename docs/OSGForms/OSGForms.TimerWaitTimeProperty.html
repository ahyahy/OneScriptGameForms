Таймер.Интервал (Timer.WaitTime) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает время, необходимое для завершения таймера, в миллисекундах.

Примечание

Пример

Таймер1.Интервал = 800;
Полный пример кода 



Перем ИФ, Таймер1, Уведомление1;

Процедура ОдноразовыйТаймер() Экспорт
	Сообщить("ОдноразовыйТаймер " + ИФ.ТекущаяДатаСМиллисекундами());
	
	Сообщить("Таймер1.Интервал = " + Таймер1.Интервал);
	
	ИФ.СообщитьЕслиЛожь(Таймер1.Интервал = 800
	, "Таймер.Интервал (Timer.WaitTime) Свойство");
	
	Таймер1.Остановить();
	
	ИФ.Завершить();
