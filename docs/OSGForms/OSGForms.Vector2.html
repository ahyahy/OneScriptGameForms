Вектор2 (Vector2) Класс

Описание

Двумерный 2D вектор, использующий координаты с плавающей точкой. Структура из 2 элементов, которая может использоваться для представления 2D-координат или любой другой пары числовых значений. Она использует координаты с плавающей точкой.
