Графика.РисоватьДугу (Graphics.DrawArc) Метод

Синтаксис

РисоватьДугу(<Центр>, <Радиус>, <НачальныйУгол>, <КонечныйУгол>, <КоличествоТочек>, <Цвет>, <Ширина>, <Сглаживание>)

Параметры

Центр (обязательный)
Тип: Вектор2 (Vector2).
Положение центра.
Радиус (обязательный)
Тип: Число.
Радиус дуги.
НачальныйУгол (обязательный)
Тип: Число.
Начальный угол.
КонечныйУгол (обязательный)
Тип: Число.
Конечный угол.
КоличествоТочек (обязательный)
Тип: Число.
Количество точек.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет дуги.
Ширина (необязательный)
Тип: Число.
Ширина обводки. Если параметр отрицательный, будут нарисованы двухточечные примитивы вместо четырехточечных. Это означает, что при масштабировании линии останутся тонкими. Если такое поведение нежелательно, передайте положительный параметр, например 1.0. Значение по умолчанию - -1.0. Параметр эффективен только в том случае, если параметр Заполнение равен Ложь.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует незаполненную дугу между заданными углами с равномерными значениями цвета и ширины и опциональным сглаживанием (поддерживается только для положительных значений ширины). Чем больше значение КоличествоТочек, тем плавнее кривая.

Примечание

Чем больше значение КоличествоТочек, тем плавнее кривая.

Дуга рисуется от НачальныйУгол к значению КонечныйУгол, то есть по часовой стрелке, если НачальныйУгол меньше чем КонечныйУгол, и против часовой стрелки в противном случае. Прохождение тех же углов, но в обратном порядке, даст ту же дугу.

Пример

Радиус = 60;
Графика1.РисоватьДугу(ИФ.Вектор2(190, 100), Радиус, 40, 43, 200, Иф.Цвет.БледноЗеленый, 5);
