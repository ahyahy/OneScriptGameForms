ТемаНадпись (ThemeLabel) Свойства

Свойства

ИмяРесурса (ResourceName) (унаследовано от Ресурс (Resource)) Необязательное имя для этого ресурса. Значение по умолчанию - "ThemeLabel".
ИнтервалАбзаца (ParagraphSpacing) Возвращает или задает вертикальный интервал между абзацами. Добавляется поверх МежстрочныйИнтервал (LineSpacing). Значение по умолчанию - 0.
КлючЭлемента (ItemKey) (унаследовано от ОбъектГодо (GObject)) Возвращает уникальный ключ элемента сгенерированный при создании.
МасштабПоУмолчанию (DefaultBaseScale) (унаследовано от Тема (Theme)) Возвращает или задает базовый масштабный коэффициент по умолчанию для этого ресурса темы. Используется некоторыми элементами управления для масштабирования их визуальных свойств на основе глобального масштабного коэффициента. Если это значение установлено на 0.0, используется глобальный масштабный коэффициент. Значение по умолчанию - 0.0.
МежстрочныйИнтервал (LineSpacing) Возвращает или задает дополнительный вертикальный интервал между строками (в пикселях), интервал добавляется к спуску строки. Это значение может быть отрицательным. Значение по умолчанию - 3.
Метка (Tag) (унаследовано от ОбъектГодо (GObject)) Возвращает или задает объект, содержащий дополнительные данные.
ПриФокусировке (Focus) Возвращает или задает стиль панели, используемый, когда надпись находится в фокусе.
ПутьРесурса (ResourcePath) (унаследовано от Ресурс (Resource)) Возвращает или задает уникальный путь к этому ресурсу. Если он был сохранен на диске, значением будет его путь к файлу.
РазмерКонтура (OutlineSize) Возвращает или задает размер контура текста. Значение по умолчанию - 0. Не рекомендуется использовать значение, превышающее половину размера шрифта, так как в этом случае контур шрифта может не полностью закрыться.
РазмерКонтураТени (ShadowOutlineSize) Возвращает или задает размер контура тени. Значение по умолчанию - 1.
РазмерШрифта (FontSize) Возвращает или задает размер шрифта текста надписи.
РазмерШрифтаПоУмолчанию (DefaultFontSize) (унаследовано от Тема (Theme)) Возвращает или задает размер шрифта по умолчанию для этого ресурса темы. Используется как значение по умолчанию при попытке получить значение размера шрифта, которого нет в этой теме или которое находится в недопустимом состоянии. Если размер шрифта по умолчанию также отсутствует или недопустим, используется резервное значение движка. Значения ниже 1 недействительны и могут использоваться для сброса свойства. Значение по умолчанию - -1.
СмещениеТениИгрек (ShadowOffsetY) Возвращает или задает вертикальное смещение тени текста. Значение по умолчанию - 1.
СмещениеТениИкс (ShadowOffsetX) Возвращает или задает горизонтальное смещение тени текста. Значение по умолчанию - 1.
Стандартное (Normal) Возвращает или задает стиль панели по умолчанию для надписи.
ЦветКонтураШрифта (FontOutlineColor) Возвращает или задает цвет контура текста надписи.
ЦветТениШрифта (FontShadowColor) Возвращает или задает цвет тени текста надписи.
ЦветШрифта (FontColor) Возвращает или задает цвет текста надписи по умолчанию.
Шрифт (Font) Возвращает или задает шрифт, используемый для текста надписи.
ШрифтПоУмолчанию (DefaultFont) (унаследовано от Тема (Theme)) Возвращает или задает шрифт по умолчанию этого ресурса темы. Используется как значение по умолчанию при попытке получить ресурс шрифта, который не существует в этой теме или находится в недопустимом состоянии. Если шрифт по умолчанию также отсутствует или недопустим, используется резервное значение движка.
