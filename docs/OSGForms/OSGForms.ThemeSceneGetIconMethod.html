ТемаСцена.ПолучитьЗначок (ThemeScene.GetIcon) Метод

Синтаксис

ПолучитьЗначок(<ИмяСвойстваТемы>)

Параметры

ИмяСвойстваТемы (обязательный)
Тип: Произвольный.
Одно из значений перечисления, содержащего имена свойств темы для соответствующего типа узла.

Возвращаемое значение

Тип: ТекстураИзИзображения (ImageTexture).

Значок для свойства темы.

Описание

Возвращает значок для свойства темы, если он существует. Возвращает значение значка резервного движка, если свойство не существует.

Примечание

Пример

ЗначокЗакрытия = ТемаСцена1.ПолучитьЗначок(Иф.ИмяСвойстваТемыОкно.ЗначокЗакрытия);
Сообщить("ЗначокЗакрытия = " + ЗначокЗакрытия);
