Камера3д (Camera3D) Класс

Описание

Представляет специальный узел, который отображает то, что видно из его текущего местоположения.

Это узел, который определяет точку обзора и параметры проекции для отображения 3D-мира на экране. Без активной камеры игрок не увидит сцену: именно она преобразует трехмерные координаты объектов в двухмерное изображение. В сцене может находиться множество камер, но в каждый момент времени активна только одна (та, у которой вызван метод СделатьТекущей (MakeCurrent)).

Основные возможности

Типы проекции
  • Перспективная: Объекты уменьшаются по мере удаления, создавая эффект глубины и реалистичности. Используется в большинстве 3D-игр.
  • Ортогональная (Изометрическая): Объекты сохраняют свой размер независимо от расстояния. Используется для стратегий, архитектурных визуализаций и стилизованных 2.5D-игр.
    • Настройка обзора
  • Параметр УголОбзора (FOV) определяет, насколько "широко" смотрит камера.
  • Малый угол обзора (например, 30°) создает эффект телеобъектива (приближение).
  • Большой угол (например, 90° и более) создает эффект "рыбьего глаза" (широкий обзор, но с искажением краев).
    • Управление окружением
  • Камера может иметь собственное свойство Окружение (Environment), переопределяющее глобальные настройки сцены (туман, свечение, небо) только для этого вида.
    • Проекция интерфейса (GUI)
  • Позволяет привязывать 2D-интерфейс (Контрол) непосредственно к камере, чтобы он всегда был виден поверх 3D-мира (например, прицел или имя над головой персонажа).
