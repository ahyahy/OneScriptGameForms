Графика (Graphics) Класс

Описание

Класс для рисования. Фактически класс Графика (Graphics) представляет собой класс Узел2д (Node2D) со всеми его свойствами и наследованием. Он обособлен под новым именем для удобства рисования таких объектов как квадраты, линии, треугольники, круги и прочие геометрические фигуры.
