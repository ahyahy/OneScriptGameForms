СтильПанелиТекстура.ОтступСнизу (StyleBoxTexture.ContentMarginBottom) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает нижнее поле для содержимого этого блока стиля. Увеличение этого значения уменьшает доступное для содержимого пространство снизу. Значение по умолчанию - -1.

Примечание

Код, использующий этот блок стиля, должен решить, что это за содержимое: например, Кнопка (Button) учитывает это поле содержимого для текстового содержимого кнопки.

Пример

СтильПанелиТекстура1.ОтступСнизу = 200;
Полный пример кода 



Перем ИФ, Кнопка1, СтильПанелиТекстура1;

	Сообщить("ОдноразовыйТаймер " + ИФ.ТекущаяДатаСМиллисекундами());
	Кнопка1.УстановитьФокус();

	ИФ.Завершить();
