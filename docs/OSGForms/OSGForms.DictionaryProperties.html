Словарь (Dictionary) Свойства

Свойства

Значения (Values) Возвращает массив, содержащий значения словаря в произвольном порядке. Порядок значений не задан, но он совпадает с порядком связанных ключей.
Ключи (Keys) Возвращает массив, содержащий ключи словаря в произвольном порядке. Порядок ключей не задан, но он совпадает с порядком значений.
Количество (Count) Возвращает количество пар ключ-значение, содержащихся в словаре.
