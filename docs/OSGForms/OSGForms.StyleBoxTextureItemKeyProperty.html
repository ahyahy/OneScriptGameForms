СтильПанелиТекстура.КлючЭлемента (StyleBoxTexture.ItemKey) Свойство

Использование

Только чтение.

Значение

Тип: Строка.

Возвращает уникальный ключ элемента сгенерированный при создании.

Примечание

Пример

Стиль2 = СтильПанелиТекстура1.Дублировать();
Сообщить("Стиль2.КлючЭлемента " + Стиль2.КлючЭлемента);
