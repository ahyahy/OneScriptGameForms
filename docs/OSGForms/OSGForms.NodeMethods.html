Узел (Node) Методы

Методы

ВСтроку (ToString) (унаследовано от ОбъектГодо (GObject)) Возвращает строковое представление данного объекта.
ДобавитьДочерний (AddChild) Добавляет дочерний элемент.
НаЗаднийПлан (SendToBack) Перемещает элемент в коллекции дочерних элементов родителя на задний план.
НаПереднийПлан (BringToFront) Перемещает элемент в коллекции дочерних элементов родителя на передний план.
ПолучитьДочерние (GetChildren) Возвращает все дочерние элементы этого узла.
ПолучитьОкно (GetWindow) Возвращает объект Окно (Window), содержащее этот узел. Если узел находится в главном окне, это эквивалентно получению корневого узла.
ПолучитьРодителя (GetParent) Возвращает родительский элемент данного элемента или Неопределено, если у элемента нет родителя.
ПолучитьУзел (GetNode) Возвращает дочерний узел по его имени.
УдалитьДочерний (RemoveChild) Удаляет дочерний элемент из коллекции дочерних родителя. При этом сам элемент вместе со своими дочерними элементами из игровых форм НЕ удаляется.
