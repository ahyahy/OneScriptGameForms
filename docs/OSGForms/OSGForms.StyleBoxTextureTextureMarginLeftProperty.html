СтильПанелиТекстура.ВылетТекстурыСлева (StyleBoxTexture.TextureMarginLeft) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает увеличение левого поля текстуры 3×3. Более высокое значение означает, что большая часть исходной текстуры считается частью левой границы поля 3×3. Значение по умолчанию - 0.

Примечание

Пример

СтильПанелиТекстура1.ВылетТекстурыСлева = 51;
