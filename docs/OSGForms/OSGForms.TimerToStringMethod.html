Таймер.ВСтроку (Timer.ToString) Метод

Синтаксис

ВСтроку()

Возвращаемое значение

Тип: Строка (String).

Строковое представление данного объекта.

Описание

Возвращает строковое представление данного объекта.

Примечание

Пример

Сообщить("Таймер1.ВСтроку = " + Таймер1.ВСтроку());
