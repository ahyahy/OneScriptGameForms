Графика.РисоватьТекстуру (Graphics.DrawTexture) Метод

Синтаксис

РисоватьТекстуру(<Текстура>, <Позиция>, <ИзменениеЦвета>)

Параметры

Текстура (обязательный)
Тип: ТекстураИзИзображения (ImageTexture).
Текстура для отрисовки.
Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция для отрисовки текстуры.
ИзменениеЦвета (необязательный)
Тип: Цвет (Color).
Модуляция цвета. Значение по умолчанию - Белый.

Возвращаемое значение

Описание

Рисует текстуру в заданной позиции.

Примечание

Пример

Графика1 = ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.Графика());
ТекстураИзИзображения = ИФ.ТекстураИзИзображения(ОбъединитьПути(ТекущийСценарий().Каталог, "Волшебник.jpg"));
Графика1.РисоватьТекстуру(ТекстураИзИзображения, ИФ.Вектор2(10, 10), Иф.Цвет.СветлоСерый);
