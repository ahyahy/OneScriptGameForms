Надпись.ПолучитьСтильПанелиТекстура (Label.GetThemeStyleboxTexture) Метод

Синтаксис

ПолучитьСтильПанелиТекстура(<ИмяСвойстваТемыДляКонтрола>)

Параметры

ИмяСвойстваТемыДляКонтрола (обязательный)
Тип: Произвольный.
Одно из значений перечисления ИмяСвойстваТемы... для контрола.

Возвращаемое значение

Тип: СтильПанелиТекстура (StyleBoxTexture).

Стиль панели для всех экземпляров этого класса.

Описание

Возвращает объект СтильПанелиТекстура (StyleBoxTexture) с указанным именем стиля. Имя стиля - это Одно из значений перечисления ИмяСвойстваТемы... для контрола.

Примечание

Возвращает запрошенный тип стиля из первой соответствующей темы в дереве, если эта тема имеет стиль такого типа. В противном случае будет создан новый экземпляр стиля запрошенного типа.

Пример

Стиль = Надпись1.ПолучитьСтильПанелиТекстура(ИФ.ИмяСвойстваТемыНадпись.Стандартное);

	Надпись1.ДобавитьСтиль(ИФ.ИмяСвойстваТемыНадпись.Стандартное, Стиль);
	
	ИФ.СообщитьЕслиЛожь("" + Стиль.Текстура = "ИфТекстураИзИзображения"
	, "Надпись.ПолучитьСтильПанелиТекстура (Label.GetThemeStyleboxTexture) Метод");
	ИФ.Завершить();
