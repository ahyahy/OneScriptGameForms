Таймер.ПолучитьОкно (Timer.GetWindow) Метод

Синтаксис

ПолучитьОкно()

Возвращаемое значение

Тип: Окно (Window).

Описание

Возвращает объект Окно (Window), содержащее этот узел. Если узел находится в главном окне, это эквивалентно получению корневого узла.

Примечание

Пример

Сообщить("Таймер1.ПолучитьОкно = " + Таймер1.ПолучитьОкно());
