Камера3д.СмотретьИзПозиции (Camera3D.LookAtFromPosition) Метод

Синтаксис

СмотретьИзПозиции(<ПозицияНаблюдателя>, <ЦелеваяТочка>, <ВекторВерха>, <ИспользоватьПередМодели>)

Параметры

ПозицияНаблюдателя (обязательный)
Тип: Вектор3 (Vector3).
Координаты точки в пространстве, из которой ведется взгляд.
ЦелеваяТочка (обязательный)
Тип: Вектор3 (Vector3).
Координаты точки, на которую нужно смотреть.
ВекторВерха (необязательный)
Тип: Вектор3 (Vector3).
Определяет, какая сторона узла будет считаться верхней после поворота. Когда вы смотрите на точку, у вас есть свобода вращения вокруг оси взгляда (как если бы вы наклонили голову набок, продолжая смотреть в одну точку). Этот параметр фиксирует наклон. Значение по умолчанию - Вектор3(0, 1, 0). Это означает, что "верхом" считается мировая ось Y. Это стандарт для большинства случаев (персонаж стоит на земле, камера не перевернута).
ИспользоватьПередМодели (необязательный)
Тип: Булево.
Флаг, определяющий, какая локальная ось узла считается «передней» (направляющей взгляд). Если Ложь - метод использует стандартную для движка ось "вперед" (часто это -Z). Если Истина - метод попытается использовать ось, которая считается "лицом" модели (часто +Z или та, на которую смотрит меш в редакторе). Если ваша 3D-модель в редакторе нарисована так, что она "смотрит" вдоль оси +Z, а движок по умолчанию считает "передом" -Z, то без этого флага объект повернется к цели спиной. Включение флага исправит ориентацию. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Перемещает узел в указанную позицию, затем поворачивает узел так, чтобы он указывал на позицию параметра ЦелеваяТочка. Эта операция вычисляется в глобальном пространстве (относительно мира).
