ТекстураИзИзображения (ImageTexture) Класс

Описание

Представляет текстуру, созданную на основе изображения.

Это специализированный тип текстуры Текстура2д (Texture2D), который создается и управляется программно на основе данных объекта Изображение (Image). В отличие от обычных текстур, загружаемых из файлов, этот класс предназначен для динамической генерации графики, изменения пикселей в реальном времени или создания текстур на лету без сохранения промежуточных файлов на диск. Это основной инструмент для процедурной генерации, рисования в игре, создания мини-карт, эффектов искажения или любых задач, где содержимое текстуры должно меняться во время выполнения программы.

Основные возможности

Создание из объекта Изображение (Image)
  • Принимает объект Изображение (Image) (который хранит данные пикселей в оперативной памяти CPU) и конвертирует его в текстуру для видеокарты (GPU).
  • Позволяет манипулировать пикселями через удобные методы класса Изображение (Image) (рисование линий, заполнение, смешивание цветов), а затем мгновенно обновлять текстуру.
    • Динамическое обновление
  • Поддержывает частичное обновление: можно изменить только часть пикселей в объекте Изображение (Image) и вызвать метод обновления, не пересоздавая всю текстуру заново. Это критически важно для производительности при частых изменениях.
    • Гибкость форматов
  • Поддержает создание текстур различных форматов (с альфа-каналом, без него, сжатые, с высокой цветовой глубиной), задаваемых при создании объекта Изображение (Image).
    • Процедурная генерация
  • Идеален для создания шумов, ландшафтов, портретов персонажей, динамических иконок или эффектов, которые невозможно заранее нарисовать художнику.
