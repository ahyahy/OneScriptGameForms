СтильПанелиПлоский.СмещениеТени (StyleBoxFlat.ShadowOffset) Свойство

Использование

Чтение и запись.

Значение

Тип: Вектор2 (Vector2).

Возвращает или задает смещение тени в пикселях. Регулирует положение тени относительно объекта. Значение по умолчанию - Вектор2(0, 0).

Примечание

Пример

Сообщить("СмещениеТени = " + Строка(ТипЗнч(ПанельныйКонтейнер1.ПолучитьСтильПанелиПлоский(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель).СмещениеТени)));
Полный пример кода 



Перем ИФ, ПанельныйКонтейнер1, СтильПанелиПлоский1;

Процедура ОдноразовыйТаймер() Экспорт
	Сообщить("ОдноразовыйТаймер " + ИФ.ТекущаяДатаСМиллисекундами());
	
	ПанельныйКонтейнер1.ДобавитьСтиль(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель, СтильПанелиПлоский1);
	
	Сообщить("СмещениеТени = " + Строка(ТипЗнч(ПанельныйКонтейнер1.ПолучитьСтильПанелиПлоский(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель).СмещениеТени)));
