Графика.НаПереднийПлан (Graphics.BringToFront) Метод

Синтаксис

НаПереднийПлан()

Возвращаемое значение

Описание

Перемещает элемент в коллекции дочерних элементов родителя на передний план.

Примечание

Пример

Процедура Таймер1_ПриСрабатыванииТаймера() Экспорт
	Если Счетчик = 1 Тогда
		Графика1.НаПереднийПлан();
	ИначеЕсли Счетчик = 2 Тогда
		Графика2.НаПереднийПлан();
	ИначеЕсли Счетчик = 3 Тогда
		Графика3.НаПереднийПлан();
	ИначеЕсли Счетчик = 4 Тогда
		Графика4.НаПереднийПлан();
	ИначеЕсли Счетчик = 5 Тогда
		Графика5.НаПереднийПлан();
		Счетчик = 0;
	КонецЕсли;	
	Уведомление1.Текст = Индексы();
	Счетчик = Счетчик + 1;
КонецПроцедуры
