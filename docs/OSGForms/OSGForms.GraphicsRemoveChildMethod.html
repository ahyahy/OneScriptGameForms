Графика.УдалитьДочерний (Graphics.RemoveChild) Метод

Синтаксис

УдалитьДочерний(<Элемент>)

Параметры

Элемент (обязательный)
Тип: Произвольный.
Дочерний удаляемый элемент.

Возвращаемое значение

Описание

Удаляет дочерний элемент из коллекции дочерних родителя. При этом сам элемент вместе со своими дочерними элементами из игровых форм НЕ удаляется.

Примечание

Пример

Графика1.УдалитьДочерний(Графика5);
