ТемаСцена.ОчиститьШрифт (ThemeScene.ClearFont) Метод

Синтаксис

ОчиститьШрифт(<ИмяСвойстваТемы>)

Параметры

ИмяСвойстваТемы (обязательный)
Тип: Произвольный.
Одно из значений перечисления, содержащего имена свойств темы для соответствующего типа узла.

Возвращаемое значение

Описание

Удаляет свойство шрифта, если оно существует. Не выполняется, если свойство не существует.

Примечание

Пример

ТемаСцена1.ОчиститьШрифт(Иф.ИмяСвойстваТемыОкно.ШрифтЗаголовка);
Полный пример кода 



Перем ИФ, ТемаСцена1, ПутьШрифта;

	Шрифт_После_ПутьРесурса = Шрифт_После.ПутьРесурса;
