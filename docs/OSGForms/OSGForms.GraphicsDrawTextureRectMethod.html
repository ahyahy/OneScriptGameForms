Графика.РисоватьТекстуруПоПрямоугольнику (Graphics.DrawTextureRect) Метод

Синтаксис

РисоватьТекстуруПоПрямоугольнику(<Текстура>, <Прямоугольник>, <Плитка>, <ИзменениеЦвета>, <Транспонировать>)

Параметры

Текстура (обязательный)
Тип: ТекстураИзИзображения (ImageTexture).
Текстура для отрисовки.
Прямоугольник (обязательный)
Тип: Прямоугольник2 (Rect2).
Прямоугольник для отрисовки текстуры.
Плитка (обязательный)
Тип: Булево.
Если параметр имеет значение Ложь (по умолчанию): Текстура рисуется один раз в указанном прямоугольнике. Если прямоугольник больше самой текстуры, текстура просто растянется, чтобы заполнить всё пространство.
Если параметр имеет значение Истина: Текстура не растягивается. Вместо этого она начинает "клонироваться" (копироваться) по горизонтали и вертикали, заполняя собой весь заданный прямоугольник, как настоящая плитка на стене.
ИзменениеЦвета (необязательный)
Тип: Цвет (Color).
Модуляция цвета. Значение по умолчанию - Белый.
Транспонировать (необязательный)
Тип: Булево.
Если параметр имеет значение Истина, координаты X и Y текстуры будут поменяны местами.

Возвращаемое значение

Описание

Рисует текстурированный прямоугольник в заданной позиции, при необходимости модулированный цветом.

Примечание

Пример

ТекстураИзИзображения = ИФ.ТекстураИзИзображения(ОбъединитьПути(ТекущийСценарий().Каталог, "Волшебник.jpg"));
Прямоугольник22 = ИФ.Прямоугольник2(ИФ.Вектор2(10, 10), ИФ.Вектор2(220, 170));
Графика1.РисоватьТекстуруПоПрямоугольнику(ТекстураИзИзображения, Прямоугольник22, Истина, Иф.Цвет.СветлоСиний, Истина);
