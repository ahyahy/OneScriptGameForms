Холст.РисоватьКруг (CanvasItem.DrawCircle) Метод

Синтаксис

РисоватьКруг(<Позиция>, <Радиус>, <Цвет>, <Заливка>, <Ширина>, <Сглаживать>)

Параметры

Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция в локальном пространстве.
Радиус (обязательный)
Тип: Число.
Радиус круга.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет круга.
Заливка (необязательный)
Тип: Булево.
Если этот параметр равен Истина, круг будет залит указанным в параметре Цвет цветом. Если тот параметр равен Ложьа, круг будет нарисован как обводка с заданными в параметре Цвет цветом и шириной, заданной в параметре Ширина. Значение по умолчанию - Истина.
Ширина (необязательный)
Тип: Число.
Ширина обводки круга. Значеие по умолчанию - -1.0
Сглаживать (необязательный)
Тип: Булево.
Если этот параметр равен Истина, к границе будут прикреплены полупрозрачные "перья", делающие контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует круг в локальном пространстве.
