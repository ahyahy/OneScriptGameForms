Кнопка.ПриПереключении (Button.Toggled) Событие

Использование

Чтение и запись.

Значение

Тип: Действие (Action).

Возвращает или задает код, выполняемый когда кнопка была просто переключена между нажатым и нормальным состояниями (только если свойство РежимПереключателя (ToggleMode) установлено в значение Истина).

Примечание

Аргументы события

Включено (ToggledOn) Возвращает флаг переключения кнопки во включенное состояние.
Отправитель (Sender) Возвращает источник (объект) последнего события.
Параметр (Parameter) Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.

Пример

Кнопка1.ПриПереключении = ИФ.Действие(ЭтотОбъект, "Кнопка1_ПриПереключении");
