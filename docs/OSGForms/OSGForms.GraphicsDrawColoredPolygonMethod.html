Графика.РисоватьЦветнойМногоугольник (Graphics.DrawColoredPolygon) Метод

Синтаксис

РисоватьЦветнойМногоугольник(<Точки>, <Цвет>, <ВнутренниеКоординаты>, <Текстура2д>)

Параметры

Точки (обязательный)
Тип: Массив.
Массив точек многоугольника.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет многоугольника.
ВнутренниеКоординаты (необязательный)
Тип: Массив.
Массив из точек, представленных объектом Вектор2 (Vector2). Это координаты XY, но внутри картинки. Разрешается превышать размер картинки.
Текстура2д (необязательный)
Тип: Текстура2д (Texture2D).
Текстура2д.

Возвращаемое значение

Описание

Рисует цветной многоугольник с любым количеством точек, выпуклый или вогнутый.

Примечание

Пример

Графика1.РисоватьЦветнойМногоугольник(Массив1, Иф.Цвет.БелаяДымка, Массив3, ТекстураИзИзображения);
