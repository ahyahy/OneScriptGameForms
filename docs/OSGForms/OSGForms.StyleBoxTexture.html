СтильПанелиТекстура (StyleBoxTexture) Класс

Описание

Представляет текстурный девяти-сторонний стиль панели.

Это ресурс оформления, который использует изображение (ТекстураИзИзображения (ImageTexture)) для отрисовки фона элемента интерфейса. В отличие от программного рисования (СтильПанелиПлоский (StyleBoxFlat)), этот класс позволяет применять сложные художественные рамки, узоры, градиенты с шумами или любые другие текстуры, созданные художником. Главная особенность этого класса - поддержка 9-частного масштабирования (9-Patch Scaling). Это позволяет растягивать текстуру на кнопки и окна любого размера, сохраняя углы и границы четкими и не искаженными.

Основные возможности

9-частное масштабирование
  • Текстура виртуально делится на 9 частей: 4 угла, 4 края и центр.
  • Углы никогда не растягиваются (сохраняют оригинальный размер и пропорции).
  • Края растягиваются только в одном направлении (верх/низ - по горизонтали, лево/право - по вертикали).
  • Центр растягивается во все стороны, заполняя оставшееся пространство.
  • Это критически важно для создания рамок, которые выглядят аккуратно на кнопках любого размера.
    • Настройка зон масштабирования
  • Свойства Margin* определяют координаты, где начинаются и заканчиваются несжимаемые углы. Эти значения задаются в пикселях относительно исходного размера текстуры.
    • Модуляция цвета
  • Свойство ИзменениеЦвета (ModulateColor) позволяет наложить цветовой фильтр поверх текстуры. Это удобно для создания вариантов одной и той же рамки (например, красная, синяя, золотая) без необходимости рисовать отдельные картинки для каждого цвета.
    • Внутренние отступы
  • Позволяет задать отступы для содержимого (текста, иконок), чтобы они не наезжали на декоративные элементы рамки. Часто эти отступы совпадают с зонами масштабирования, но могут быть настроены независимо.
    • Сглаживание
  • Поддерживает фильтрацию текстуры, чтобы при масштабировании пиксель-арт оставался четким (если отключить сглаживание) или плавным (для HD-графики).
