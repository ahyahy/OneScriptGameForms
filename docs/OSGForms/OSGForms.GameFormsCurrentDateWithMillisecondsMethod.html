ИгровыеФормы.ТекущаяДатаСМиллисекундами (GameForms.CurrentDateWithMilliseconds) Метод

Синтаксис

ТекущаяДатаСМиллисекундами()

Возвращаемое значение

Тип: Строка.

Строка с датой с миллисекундами.

Описание

Возвращает строку с текущей (системной) датой на компьютере с миллисекундами до седьмого знака.

Примечание

Дата выводится в соответствии с форматной строкой [dd:MM:yyyy HH:mm:ss.fffffff]. Буквы f отвечают за дробную часть секунды (то есть за доли секунды после точки).

Как работает f в зависимости от количества символов.
f — одна самая старшая цифра доли секунды (десятые доли, то есть 0–9).
f — две цифры (сотые доли).
f — три цифры (тысячные доли, это уже миллисекунды).
…
f — семь цифр (десятимиллионные доли секунды).
То есть количество f задаёт, сколько знаков после запятой будет показано.

Пример

Сообщить("ОдноразовыйТаймер " + ИФ.ТекущаяДатаСМиллисекундами());
