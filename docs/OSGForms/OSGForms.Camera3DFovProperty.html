Камера3д.УголОбзора (Camera3D.Fov) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает угол поля зрения камеры (в градусах). Применимо только в режиме перспективы. Значение по умолчанию - 75.0.

Для справки, значение вертикального поля зрения по умолчанию (75.0) эквивалентно горизонтальному углу обзора:
  • ~91,31 градуса в окне просмотра 4:3
  • ~101,67 градуса в окне просмотра 16:10
  • ~107,51 градуса в окне просмотра 16:9
  • ~121,63 градуса в окне просмотра 21:9
