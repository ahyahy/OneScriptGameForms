Кнопка.Нажатие (Button.Pressed) Событие

Использование

Чтение и запись.

Значение

Тип: Действие (Action).

Возвращает или задает код, выполняемый когда кнопка переключается или нажимается.

Примечание

Аргументы события

Отправитель (Sender) Возвращает источник (объект) последнего события.
Параметр (Parameter) Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.

Пример

Кнопка1.Нажатие = ИФ.Действие(ЭтотОбъект, "Кнопка1_Нажатие");
