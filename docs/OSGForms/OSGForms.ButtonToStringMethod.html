Кнопка.ВСтроку (Button.ToString) Метод

Синтаксис

ВСтроку()

Возвращаемое значение

Тип: Строка (String).

Строковое представление данного объекта.

Описание

Возвращает строковое представление данного объекта.

Примечание

Пример

Сообщить("Кнопка1.ВСтроку = " + Кнопка1.ВСтроку());
