Строка.ПоследнееВхождение (String.LastIndexOf) Метод

Синтаксис

ПоследнееВхождение(<ИскомаяСтрока>)

Параметры

ИскомаяСтрока (обязательный)
Тип: Строка.
Строка для поиска.

Возвращаемое значение

Тип: Число.

Отсчитываемый от нуля индекс, если эта строка найдена, или -1, если она не найдена.

Описание

Возвращает отсчитываемый от нуля индекс последнего вхождения указанной строки в этом экземпляре строки.

Примечание

Пример

Стр = "Детям - мороженое, его бабе - цветы. Смотри не перепутай! Кутузов!";
ИФСтрока = ИФ.Строка(Стр);
Сообщить("ИФСтрока = " + ИФСтрока);
Сообщить("ИФСтрока.ПоследнееВхождение(""ай"") = " + ИФСтрока.ПоследнееВхождение("ай"));
