Кнопка.Текст (Button.Text) Свойство

Использование

Чтение и запись.

Значение

Тип: Строка.

Возвращает или задает текст кнопки, который будет отображаться внутри области кнопки. Значение по умолчанию - "".

Примечание

Пример

Кнопка1.Текст = "Нажми меня";
Полный пример кода 



Перем ИФ, Кнопка1;

Процедура Кнопка1_Нажатие() Экспорт
	Сообщить("Кнопка1.Текст = " + Кнопка1.Текст);
	ИФ.СообщитьЕслиЛожь(Кнопка1.Текст = "Нажми меня", "Кнопка.Текст (Button.Text) Свойство");
	ИФ.Завершить();
КонецПроцедуры
