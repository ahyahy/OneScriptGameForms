ШрифтВариативный (FontVariation) Класс

Описание

Предоставляет вариации OpenType, имитацию жирного/наклонного начертания и дополнительные настройки шрифта.

Это ресурс-обертка, который позволяет тонко настраивать параметры шрифта (жирность, ширину, наклон) без необходимости загружать отдельные файлы для каждого начертания. Он ссылается на базовый шрифт и применяет к нему дополнительные настройки осей вариации или фиксированные стили. Этот класс является ключевым инструментом для работы с современными вариативными шрифтами (Variable Fonts), где один файл .ttf или .otf содержит бесконечное множество начертаний, но также полезен для принудительного изменения свойств обычных шрифтов (например, сделать шрифт искусственно жирнее или уже).

Основные возможности

Настройка осей вариации (Variable Axes)
  • Позволяет программно задавать числовые значения для осей, поддерживаемых шрифтом:
  • Вес (Weight): Плавная регулировка от тонкого (100) до сверхжирного (900).
  • Ширина (Width): Изменение пропорций от узких до широких.
