ИгровыеФормы.НовыйОбъект (GameForms.NewObject) Метод

Синтаксис

НовыйОбъект(<ИмяКласса>)

Параметры

ИмяКласса (обязательный)
Тип: Строка.
Русскоязычное или англоязычное имя класса.

Возвращаемое значение

Тип: Произвольный.

Описание

Возвращает экземпляр класса по имени, переданном в параметре.

Примечание

Пример

ИмяОбъекта = "ПанельныйКонтейнер";
Панели = Новый Структура();
Для А = 1 По 9 Цикл
	Панели.Вставить(ИмяОбъекта + А, ИФ.КорневоеОкно.ДобавитьДочерний(ИФ.НовыйОбъект(ИмяОбъекта)));
	Эл = Панели[ИмяОбъекта + А];
	Эл.Размер = Размер1;
	Эл.ДобавитьСтиль(ИФ.ИмяСвойстваТемыПанельныйКонтейнер.Панель, СтильПанелиПлоский1);
КонецЦикла;
