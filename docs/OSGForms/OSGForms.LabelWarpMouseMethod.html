Надпись.ПереместитьМышь (Label.WarpMouse) Метод

Синтаксис

ПереместитьМышь(<Позиция>)

Параметры

Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция для перемещения, относительно позиции объекта.

Возвращаемое значение

Описание

Перемещает курсор мыши в позицию, относительно позиции объекта.

Примечание

Пример

ПозицияИкс1 = Надпись1.Позиция.Икс;
Сообщить("До ПозицияИкс1 =  " + ПозицияИкс1);
Надпись1.ПереместитьМышь(ИФ.Вектор2(100, 100));
ПозицияИкс2 = ИФ.ПолучитьПозициюМыши().Икс;
Сообщить("После ПозицияИкс2 =  " + ПозицияИкс2);
