СтильПанелиПлоский.Дублировать (StyleBoxFlat.Duplicate) Метод

Синтаксис

Дублировать()

Возвращаемое значение

Тип: Ресурс (Resource).

Копия исходного ресурса.

Описание

Дублирует этот ресурс, возвращая новый ресурс со свойствами, скопированными из исходного.

Примечание

Пример

СтильПоУмолчанию3 = СтильПоУмолчанию2.Дублировать();
Полный пример кода
