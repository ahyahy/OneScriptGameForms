РежимФокусировки (FocusMode) Перечисление

Описание

Указывает возможности захвата фокуса узлом.

Это набор констант, определяющих, может ли элемент управления (кнопка, поле ввода, слайдер) получать фокус ввода от клавиатуры, геймпада или навигации джойстиком, и при каких условиях. Это ключевой механизм для создания интерфейсов, доступных для управления без мыши. Он позволяет разработчику решить, какие элементы должны реагировать на нажатие Tab или стрелки на геймпаде, а какие — оставаться пассивными до прямого клика мышью.

Члены

Имя члена Описание Значение
Все (All) Узел может захватывать фокус по щелчку мыши, используя стрелки и клавиши Tab на клавиатуре или кнопки D-pad на геймпаде. 2
Доступность (Accessibility) Узел может захватить фокус только когда активен экранный диктор. 3
Клик (Clik) Узел может захватывать фокус только по щелчкам мыши. 1
Отсутствие (None) Узел не может захватить фокус. 0
