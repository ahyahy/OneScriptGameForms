ИгровыеФормы.Загрузить (GameForms.Load) Метод

Синтаксис

Загрузить(<Путь>)

Параметры

Путь (обязательный)
Тип: Строка.
Путь к ресурсу.

Возвращаемое значение

Тип: Произвольный.

Описание

Загружает ресурс по указанному пути.

Примечание

Пример

СтильПанелиЛиния2 = ИФ.Загрузить(ПутьКопииРесурса);
