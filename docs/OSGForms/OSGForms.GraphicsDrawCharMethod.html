Графика.РисоватьСимвол (Graphics.DrawChar) Метод

Синтаксис

РисоватьСимвол(<Шрифт>, <Позиция>, <Символ>, <РазмерШрифта>, <ИзменениеЦвета>, <ДискретноеПреобразование>)

Параметры

Шрифт (обязательный)
Тип: Шрифт (Font).
Шрифт символа.
Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция символа.
Символ (обязательный)
Тип: Строка.
Первый символ переданной в параметре строки.
РазмерШрифта (необязательный)
Тип: Число.
Размер шрифта. Значение по умолчанию - 16.
ИзменениеЦвета (необязательный)
Тип: Цвет (Color).
Модуляция цвета. Значение по умолчанию - Белый.
ДискретноеПреобразование (необязательный)
Тип: Число.
Если параметр больше нуля, он используется как коэффициент передискретизации шрифта, в противном случае используются настройки передискретизации области просмотра. Значение по умолчанию - 0.

Возвращаемое значение

Описание

Рисует первый символ строки, используя пользовательский шрифт.

Примечание

Пример

ШрифтВариативный1 = ИФ.ШрифтВариативный(ОбъединитьПути(ТекущийСценарий().Каталог, "tahoma.ttf"));
Графика1.РисоватьСимвол(ШрифтВариативный1, ИФ.Вектор2(5, 42), "Буква", 42, Иф.Цвет.БледноЗеленый);
