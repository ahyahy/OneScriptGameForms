Графика.РисоватьПунктирнуюЛинию (Graphics.DrawDashedLine) Метод

Синтаксис

РисоватьПунктирнуюЛинию(<ИсходнаяТочка>, <КонечнаяТочка>, <Цвет>, <Ширина>, <ДлинаШтриха>, <Выравнивание>, <Сглаживание>)

Параметры

ИсходнаяТочка (обязательный)
Тип: Вектор2 (Vector2).
Точка начала линии.
КонечнаяТочка (обязательный)
Тип: Вектор2 (Vector2).
Точка окончания линии.
Цвет (обязательный)
Тип: Цвет (Color).
Цвет линии.
Ширина (необязательный)
Тип: Число.
Ширина линии. Значение по умолчанию - -1.0.
ДлинаШтриха (необязательный)
Тип: Число.
Длина каждого штриха в пикселях, при этом зазор между штрихами будет такой же длины.. Значение по умолчанию - 2.0.
Выравнивание (необязательный)
Тип: Булево.
Если параметр равен Истина, длину первого и последнего штрихов можно укоротить или удлинить, чтобы линия начиналась и заканчивалась точно в точках, заданных параметрами ИсходнаяТочка и КонечнаяТочка. Оба конца всегда симметричны, если параметр равно Истина. Если параметр равен Ложь, все штрихи будут иметь одинаковую длину, но линия может выглядеть неполной на конце из-за того, что длина штриха не делится нацело на длину линии. Если параметр равен Ложь, штрихи отображаются полностью. Значение по умолчанию - Истина.
Сглаживание (необязательный)
Тип: Булево.
Если параметр равен Истина, к границе будут добавлены полупрозрачные "перья", что сделает контуры плавными. Значение по умолчанию - Ложь.

Возвращаемое значение

Описание

Рисует пунктирную линию от одной двухмерной точки к другой заданного цвета и ширины.

Примечание

Пример

Графика1.РисоватьПунктирнуюЛинию(ИФ.Вектор2(15, 15), ИФ.Вектор2(200, 210), Иф.Цвет.ГлубокийРозовый, 8, 8);
