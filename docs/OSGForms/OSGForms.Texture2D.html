Текстура2д (Texture2D) Класс

Описание

Базовый класс. Текстура для 2D и 3D. Текстура работает путем регистрации изображения в видеооборудовании, которое затем может использоваться в 3D-моделях или 2D объектах Sprite2D или элементах управления. Текстуры часто создаются путем загрузки их из файла. Примечание: Максимальный размер текстуры составляет 16384×16384 пикселей из-за ограничений графического оборудования. Большие текстуры могут не импортироваться.

Это конкретный ресурс, представляющий собой стандартное двумерное изображение (растр), загруженное из файла. Это самый распространенный тип текстур в движке, используемый для спрайтов персонажей, фонов, иконок интерфейса, текстур материалов и любых других статичных картинок. В отличие от абстрактного класса Текстура (Texture), этот класс содержит реальные данные изображения, оптимизированные для передачи в видеокарту (GPU) и быстрой отрисовки.

Основные возможности

Загрузка из файлов
  • Автоматически импортирует изображения популярных форматов: PNG, JPG, WebP, BMP, TGA и другие.
  • При импорте движок может сжимать текстуру в специальные форматы видеокарты (например, BPTC, ETC2, S3TC) для экономии видеопамяти и ускорения рендеринга.
    • Настройки импорта
  • Позволяет управлять качеством, сжатием, наличием альфа-канала (прозрачности) и режимом фильтрации (пиксельная или плавная) прямо в настройках ресурса.
  • Поддерживает создание мип-мапов (уменьшенных копий текстуры) для корректного отображения объектов вдали.
    • Использование в UI и 2D/3D
  • Является основным типом данных для свойства Текстура (Текстура) у узлов Спрайт2д, Кнопка, Спрайт3д и др.
    • Программное создание
  • Может быть создана динамически из объекта Изображение (Image) во время выполнения игры, если нужно сгенерировать картинку кодом или изменить пиксели на лету.
