Цвет (Color) Класс

Описание

Цвет, представленный в формате RGBA (красный, зеленый, синий, альфа-канал).

Этот класс является фундаментальным для всей графики в движке: он используется для окрашивания спрайтов, настройки шрифтов, создания градиентов, работы с материалами и процедурной генерации текстур.

Основные возможности

Встроенные константы
  • Содержит набор готовых статических цветов для часто используемых названий: Цвет.Красный, Цвет.Зеленый, Цвет.Синий, Цвет.Белый, Цвет.Черный, Цвет.Прозрачный и многие другие.
    • Конвертация форматов
  • Умеет создавать себя из различных форматов: Из имени цвета, или строки шестнадцатиричного значения, или десятичного значения цвета.
