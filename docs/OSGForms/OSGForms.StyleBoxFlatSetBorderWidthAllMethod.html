СтильПанелиПлоский.УстановитьШиринуГраницыВсех (StyleBoxFlat.SetBorderWidthAll) Метод

Синтаксис

УстановитьШиринуГраницыВсех(<Ширина>)

Параметры

Ширина (обязательный)
Тип: Число.

Возвращаемое значение

Описание

Устанавливает ширину границы на указанное количество пикселей для всех сторон.

Примечание

Пример

СтильПанелиПлоский1.УстановитьШиринуГраницыВсех(18);
