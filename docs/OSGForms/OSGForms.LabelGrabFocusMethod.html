Надпись.УстановитьФокус (Label.GrabFocus) Метод

Синтаксис

УстановитьФокус()

Возвращаемое значение

Описание

Перехватывает фокус у другого элемента управления и становится сфокусированным элементом управления.

Примечание

Пример

Надпись1.РежимФокусировки = ИФ.РежимФокусировки.Все;
Надпись1.УстановитьФокус();
Сообщить("Надпись1.Сфокусирован() =  " + Надпись1.Сфокусирован());
