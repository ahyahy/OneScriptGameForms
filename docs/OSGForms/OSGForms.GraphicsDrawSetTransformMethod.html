Графика.Преобразовать (Graphics.DrawSetTransform) Метод

Синтаксис

Преобразовать(<Позиция>, <Поворот>, <Масштаб>)

Параметры

Позиция (обязательный)
Тип: Вектор2 (Vector2).
Позиция преобразования. Это точка относительно которой будет произведено преобразование.
Поворот (необязательный)
Тип: Число.
Величина поворота в градусах. При положительном значении поворот будет сделан против часовой стрелки.
Масштаб (необязательный)
Тип: Вектор2 (Vector2).
Масштаб преобразования по осям.

Возвращаемое значение

Описание

Задаёт пользовательское локальное преобразование для отрисовки. Всё, что будет отрисовано ПОСЛЕ ЭТОГО, будет преобразовано этим преобразованием. Метод СЛЕДУЕТ ПРИМЕНИТЬ ДО рисования первого объекта.

Примечание

Пример

Графика1.Преобразовать(ИФ.Вектор2(-80, 50), -45, ИФ.Вектор2(1.25, 1.8));
